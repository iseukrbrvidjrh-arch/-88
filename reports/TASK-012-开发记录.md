# TASK-012 开发记录

- 状态：已完成（2026-10-30，项目负责人正式验收通过）。
- 核心功能：最近 7 日/指定日期范围学习记录、学习库状态与今日到期统计、字幕 cue 与未完成复习位置持久化、重启恢复、悬空引用降级、现有前端学习记录页与“继续学习”入口。
- 统计口径：直接聚合 `review_attempt`、`learning_item` 与 `review_state`，未新增每日计数表。新增学习词条数是当天创建且 `entry_type = word` 的条目数；复习尝试次数是当天不可变 `review_attempt` 的行数；参与复习的不同词条数是当天 `learning_item_id` 去重数；正确次数仅包含 `final_rating = good`，且拼写模式还必须 `is_spelling_correct = 1`；正确率为正确次数除以尝试次数，无尝试时为“暂无”；未归档词条总数等于 `new`、`learning`、`mastered` 三种状态之和；已掌握数量只读取 BR-REV 规则产生的 `mastered` 状态，不把浏览或单次答对视为掌握；今日到期包含 `new`，以及 `next_review_date` 不晚于当前本地日期的未归档词条；AI 内容保存数是当天创建且 `saved_from_ai = 1` 的全部类型条目数。AI 单词可同时计入新增词条与 AI 保存两个不同指标，但每个指标内部均按唯一持久化条目计数。
- 日期与一致性：按注入时钟的本地日历日查询，默认最近 7 天，最长 366 天。状态总数实时读取投影，复习成功投影与原始历史不一致时返回结构化告警并写安全日志，不静默修正数据。
- 继续学习：复用已批准的 `app_setting` 键，不新增迁移或统计表。保存目标前验证字幕/cue 关系和复习词条有效性；失效引用返回 `stale_reference` 并降级到字幕库；读取过程不调用云端。
- 自动化测试：TASK-012 专项 10 项通过；TASK-001～012 全量 168 项通过；JavaScript 语法检查与 Git 差异格式检查通过。覆盖空库、单日新增、同词多次复习、跨日/跨年/时区、正确率、AI 保存、三状态与到期数、字幕归档、明细重算告警、幂等重复提交、重启恢复、悬空引用和零云端调用。
- Chrome 验收：使用隔离数据库和本机 Google Chrome Headless + DevTools Protocol 完成真实操作。原创测试字幕经“导入 → 加词 → 复习 → 学习记录 → 继续 cue”闭环；统计显示新增 1、复习 1、不同词 1、正确 1、正确率 100%；1280×800 与 1440×900 无横向溢出；断网后已加载的本地字幕/cue 仍可查看；观察到外部请求 0。
