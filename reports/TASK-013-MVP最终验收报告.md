# SceneLingo V0.1 MVP 最终工程验收报告

## 1. 结论

截至 2026-10-30，V0.1 自动化与本机 Chrome 工程验收**有条件通过**：未发现阻断级或严重级功能缺陷；本轮发现并最小修复 NFR-017“用户查看/清除日志”缺口。最终产品验收仍需项目负责人按《SceneLingo V0.1 用户验收清单》完成物理断网、另一台局域网设备、Safari 和个人主观易用性检查。本轮未调用千问、未产生模型费用、未接触真实个人学习库。

## 2. 环境与数据

- 设备：MacBook Pro，Apple M5，16 GB；macOS 26.5.1；Python 3.14.7。
- 数据：`/private/tmp` 或 Python 临时目录中的隔离 SQLite 数据库；字幕均为项目原创固定样本。
- 浏览器：本机 Google Chrome Headless，通过 DevTools Protocol 真实操作；不是 DOM 模拟器。
- 云端：假网关与阻断域名验证；本轮无真实千问调用。历史真实调用结果引用已批准的 TASK-010/011 记录，不冒充本轮调用。

## 3. 自动化、恢复与边界

- TASK-001～013 全量回归：175 项通过；1 条 FastAPI/Starlette TestClient 上游弃用警告。
- TASK-013 专项新增 7 项：时钟回拨/时区、队列变化与字幕删除后的继续学习、停止后目录备份恢复、异常进程退出、日志查看清除与隐私、Key 不落库/日志/页面、10 MB 与 20,000 cue 精确边界。
- 备份/恢复演练：在应用关闭后复制完整隔离数据目录到新位置；恢复库 `quick_check=ok`，迁移版本不重复执行，字幕、词条、复习尝试均一致。
- 异常退出：独立 Python 进程写入一个已提交设置和一个未提交设置后 `os._exit(17)`；重启后已提交值存在、未提交值不存在、数据库 `quick_check=ok`。
- 大小边界：20,000 cue 可解析；10 MB 载荷进入格式校验而非被误判超限；10 MB + 1 byte 被明确拒绝。

## 4. 性能基线

参考实测机器如 §2。固定 2,000 cue、147,781 bytes 原创 SRT：

| 指标 | 实测 | NFR-001 目标 | 结果 |
| --- | ---: | ---: | --- |
| 真实进程启动到 `/health` | 0.2427 s | ≤ 5 s | 通过 |
| 2,000 cue 导入 | 0.0183 s | ≤ 3 s | 通过 |
| 本地 IPA 查询 p95（200 次） | 0.879 ms | ≤ 200 ms | 通过 |
| 复习保存 p95（100 次） | 0.643 ms | ≤ 300 ms | 通过 |
| 本机 TTS 请求返回 | 0.9953 s | ≤ 1 s | 通过，余量很小 |

导入/查询/保存使用同进程隔离数据库测量；冷启动和 TTS 使用真实独立进程测量。数据规模满足 P0 的 2,000 cue 基线，不代表 P1 的 100 份字幕、500,000 cue、50,000 词条容量已通过。

## 5. Chrome 与网络观察

- 完成真实操作链：启动 → 导入 → 浏览 → 加词 → IPA → 本地 TTS/停止 → 复习 → 学习记录 → 日志查看 → 受控删除 → 冻结语境与历史核对。
- 1280×800、1440×900 均无横向溢出；IPA 实际显示 `/ˈdoʊn/`；统计显示新增 1、复习 1、不同词 1、正确 1、正确率 100%。
- 删除有关联字幕后，词条仍显示冻结句子、字幕标题、“来源已不可用”和复习历史。
- Chrome 请求观察中外部请求数为 0；阻断千问域名后本地 `/health` 仍正常。该结果是浏览器域名阻断测试，不等同于用户物理关闭 Wi-Fi。
- 实际进程 `lsof` 显示只监听 `127.0.0.1`。另一台局域网设备的连接失败仍留给用户实测。

## 8. 安全、隐私与费用

- Host、Origin、无 Origin 写请求、CORS 预检、JSON Content-Type、会话 token、CSP、XSS、路径与 TTS 命令注入均有回归。
- Key 只由 SecretStore/Keychain 保存；前端、数据库、日志、错误体、URL 与发送预览无完整 Key。
- 日志是 0600 JSON 文件，仅含诊断元数据；新增受保护的查看/确认清除入口。清除后学习数据不变。
- 仓库与待提交差异执行密钥模式扫描；测试使用明确的非真实标记。
- AI 失败无 usage 时费用保持未知，不记为零；成功费用始终标注估算，不冒充供应商账单；不静默换贵模型。

## 9. 失败、未验证与已知限制

**失败项：无。**

未验证/需用户完成：

1. 另一台局域网设备不能访问的物理实测。
2. 物理关闭 Wi-Fi 后完整 UI 操作；本轮仅做域名阻断和假网关。
3. Safari 最近两个主要版本；本轮真实浏览器为 Chrome。
4. macOS 13/14 兼容性；本机为 macOS 26.5.1。
5. P1 大容量（500,000 cue/50,000 词条）和长期真实数据库性能。
6. 真实网络中 AI 流式取消的供应商侧终止时机。

已知限制：TTS 实测距 1 秒目标余量很小；Markdown 富文本未实现；系统 TTS 读音可能与 IPA 第一候选不同；词典固定样本覆盖率不能代表真实字幕；备份/恢复目前是停机复制整个数据目录，没有应用内导出按钮；一条 FastAPI/Starlette TestClient 上游弃用警告仍存在。
