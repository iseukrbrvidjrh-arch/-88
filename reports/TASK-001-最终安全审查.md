# TASK-001 最终安全审查报告

日期：2026-10-29。结论：用户已接受当前本地 HTTP 安全边界及下述残余风险，TASK-001 通过验收。

## 令牌流转

进程启动时生成随机令牌；服务端仅将它注入本机首页的动态 HTML 响应。静态 HTML/JS 源文件不含实际令牌。前端从页面读取令牌，并通过 `X-SceneLingo-Token` 请求头调用受保护 API；令牌不进入 URL、日志或数据目录，重启后更换。

## 已验证的边界

- Uvicorn 仅绑定 `127.0.0.1`；异常 Host 被拒绝。
- 外站和 `null` Origin、无 Origin 的写请求均被拒绝。
- 表单常见的 `application/x-www-form-urlencoded`、`multipart/form-data`、`text/plain` 无法通过 API 的 JSON 要求。
- 浏览器预检不返回 CORS 放行头；外站预检被拒绝。
- Chrome 从另一回环端口尝试跨源读取首页与受保护 API，均显示浏览器阻止读取。
- CSP、`nosniff`、`no-referrer` 和 `no-store` 响应头已检查。
- 自动化测试最终结果：**24 passed，1 条上游 TestClient 弃用警告**。

命令输出、端口说明和逐项核查证据见 [TASK-001 验收前核查记录](TASK-001-验收前核查.md)。

## 残余风险与待办

同机进程可请求动态首页取得令牌，并以请求头调用 API；这已由自动化测试演示。已批准的系统架构 §9.2 明确本机进程不是该机制的信任边界。可读取本应用 DOM 的恶意浏览器扩展也可能取得令牌。本任务不引入账户或操作系统级进程身份认证。

另一台局域网设备访问本机局域网 IP 的实测仍待完成；本次只验证了回环绑定和其他回环地址连接失败。上述残余与待办已由项目负责人明确接受，不阻塞 TASK-001 验收。
