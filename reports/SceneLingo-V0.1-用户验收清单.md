# SceneLingo V0.1 用户验收清单

请使用您自己创建的两三句英文测试字幕，不要使用私人影视字幕。建议先按用户指南备份现有数据，或用 `--data-dir` 指向一个新的测试目录。每项完成后在方框中打勾，并把异常现象记在末尾。

## A. 启动与本地安全

- [ ] 按用户指南启动；Chrome 能打开 `http://127.0.0.1:8765`。
- [ ] 终端显示监听 `127.0.0.1`，而不是 `0.0.0.0`。
- [ ] 刷新页面后本地功能正常；页面没有账号、多用户或云同步入口。
- [ ] 可选：用同一局域网的另一台设备访问“这台 Mac 的局域网 IP:8765”，应连接失败。

## B. 字幕、词汇、IPA 与朗读

- [ ] 导入一份原创 SRT；cue、时间轴、词次和去重词形符合原文。
- [ ] 再次导入相同内容；应用提示重复且字幕数量不增加。
- [ ] 导入含一条无效 cue 的测试文件；有效 cue 保留、无效数量正确。
- [ ] 从候选中加入一个词；学习库只有一个词条。
- [ ] 从另一 cue 再加入同一词；不重复建词条，语境数量增加。
- [ ] 打开词条详情；IPA、语境和来源可读。未知词显示“本地未收录”且应用不崩溃。
- [ ] 点击单词和句子朗读，再点击停止；声音和停止操作正常。

## C. 复习、统计与继续学习

- [ ] 完成一次正确复习和一次错误复习；历史各增加一条，下次日期符合界面结果。
- [ ] 刷新页面；已确认的尝试仍存在且没有重复。
- [ ] 学习记录中的复习次数、不同词条数、正确数和正确率与刚才操作一致。
- [ ] 学习库三种状态之和等于未归档词条总数；浏览次数没有变成掌握数。
- [ ] 在某个 cue 停留后正常停止并重启；“继续学习”能返回该字幕位置。
- [ ] 让复习队列发生变化后重启；仍有效的位置可恢复，失效位置有提示且不崩溃。

## D. 字幕生命周期与数据保留

- [ ] 归档一份字幕再恢复；cue 和统计没有丢失。
- [ ] 对有关联词条的字幕选择删除；确认提示明确说明影响。
- [ ] 选择保留冻结语境后删除；字幕从字幕库消失，但词条详情仍显示原语境和“来源已不可用”。
- [ ] 复习历史仍可打开，词条和历史没有被静默删除。

## E. AI 隐私与费用（可选，会产生真实调用费用）

若不希望产生费用，请跳过实际发送，只检查预览和取消流程。

- [ ] 未配置 Key 时，本地功能可用，云端发送被阻止并有说明。
- [ ] 输入一条原创英文问题，打开预览但点击取消；没有产生 AI 消息或学习条目。
- [ ] 预览明确列出模型、目标文本、附件和历史条数；默认历史为 0。
- [ ] 移除附件后重新预览；被移除内容不再出现。
- [ ] 如选择真实发送：只发送这次原创文本；回答有 AI 标识，费用明确为估算而非供应商账单。
- [ ] 保存 AI 内容前可以编辑；取消不保存；重复保存同类型同文本不会新增重复条目。
- [ ] 关闭云端开关后，云端入口不能发出请求，本地学习仍正常。

## F. 断网、重启、日志与备份

- [ ] 物理关闭 Wi-Fi 后，导入、浏览、IPA、TTS、加词、复习和统计仍可使用。
- [ ] 云端操作快速显示离线/失败，不无限加载、不自动重试或切换模型。
- [ ] 在“设置”查看日志；看不到字幕正文、聊天正文、完整 Key 或个人文件路径。
- [ ] 确认清除日志；学习数据仍然存在。
- [ ] 正常停止，按用户指南复制整个数据目录，再启动；数据不变。
- [ ] 用隔离测试目录执行一次恢复；字幕、词条、历史、状态与统计一致。
- [ ] 连续停止、启动两次；没有重复数据或残留服务进程。

## G. 基本易用性与兼容性

- [ ] 在 Chrome 1280×800 与 1440×900 窗口中，无横向溢出，主要按钮可见。
- [ ] 用键盘 Tab 可以到达主要按钮和输入框；焦点轮廓清楚，状态不只靠颜色表达。
- [ ] 错误提示说明发生了什么以及下一步可做什么。
- [ ] 如日常计划使用 Safari，请在当前 Safari 版本重复 A～D 的核心流程。
