# SceneLingo V0.1 用户指南

本指南面向在一台 Mac 上使用 SceneLingo 的普通用户。SceneLingo 默认只在本机运行；字幕、学习记录、AI 历史和费用记录保存在本地 SQLite 数据库中。

## 1. 首次启动

1. 打开“终端”。
2. 输入 `cd ~/Desktop/SceneLingo` 并按回车。
3. 如果项目中还没有 `.venv`，依次执行 `python3 -m venv .venv` 和 `.venv/bin/python -m pip install -r requirements.txt`。安装依赖需要访问 Python 软件源；正常使用不需要重复安装。
4. 输入 `.venv/bin/python -m app.main` 并按回车。
5. 看到 `Uvicorn running on http://127.0.0.1:8765` 后，在 Chrome 打开 <http://127.0.0.1:8765>。
6. 不要关闭正在运行程序的终端窗口。

若 8765 端口被占用，可运行 `.venv/bin/python -m app.main --port 18765`，然后打开 <http://127.0.0.1:18765>。服务仍只监听 `127.0.0.1`。

## 2. 正常停止与重新启动

- 停止：回到运行 SceneLingo 的终端，按 `Control-C`，等待出现应用关闭提示。
- 重新启动：再次执行 `.venv/bin/python -m app.main`。
- 不要直接强制结束进程；即使异常退出，已经确认保存的事务仍应保留，未完成事务会回滚。

## 3. 配置千问（可选）

本地字幕、IPA、朗读、加词、复习、统计和继续学习不需要千问。

1. 在页面打开“设置”。
2. 在 API Key 密码框中输入 Key，点击“保存 Key”。Key 只交给本机后端写入 macOS Keychain，不写入数据库或日志。
3. 勾选云端同意和云端开关，检查模型名称后保存。
4. 每次云端调用前检查发送预览；只有点击确认才会联网和产生潜在费用。
5. 不要把 Key 粘贴到聊天、字幕、命令参数或项目文件中。

## 4. 日常学习流程

1. 在“字幕库”导入 UTF-8 编码的 `.srt` 或 `.vtt` 文件。
2. 打开字幕，浏览 cue 与词汇候选。
3. 对需要学习的词点击“加入学习库”。
4. 在“学习库”查看 IPA、来源语境、朗读和历史。
5. 在“复习”加载到期队列，完成作答并确认保存。
6. 在“学习记录”核对新增词条、复习次数、不同词条数、正确率和状态数量。
7. 下次启动后用“继续学习”返回上次字幕 cue 或复习位置。

AI 回答只按纯文本显示，可能不准确。保存 AI 内容前必须检查、编辑并确认；系统不提供发音准确率评分。

## 5. 查看与清除日志

在“设置 → 本地诊断日志”中可查看最近 100 条结构化记录。日志只显示时间、级别、操作和错误码，不显示字幕、聊天正文、Key 或本地路径。点击“清除日志…”并再次确认，只会清除 SceneLingo 日志，不会删除学习数据。

## 6. 手动备份

V0.1 没有应用内导出按钮。备份必须在 SceneLingo **完全停止后**进行：

1. 按“正常停止”步骤关闭程序。
2. 在 Finder 中选择“前往 → 前往文件夹…”。
3. 输入 `~/Library/Application Support/`。
4. 将整个 `SceneLingo` 文件夹复制到个人备份位置，并命名为例如 `SceneLingo-backup-2026-10-30`。
5. 备份包含私人字幕解析内容、学习记录和 AI 历史；请放在自己控制的加密磁盘或受保护位置，不要公开上传。

如果启动时使用了 `--data-dir`，应备份该参数指定的整个目录，而不是默认目录。

## 7. 从备份恢复

恢复会改变当前使用的数据，因此先保留当前目录，避免覆盖：

1. 完全停止 SceneLingo。
2. 打开 `~/Library/Application Support/`。
3. 将当前 `SceneLingo` 改名为 `SceneLingo-before-restore-日期时间`，不要删除。
4. 把选定的完整备份文件夹复制到这里，并将副本命名为 `SceneLingo`。
5. 启动应用，检查字幕数、学习库、复习历史和统计。
6. 确认恢复正确后，是否保留旧目录由用户自行决定；SceneLingo 不会自动删除它。

若启动提示数据库版本过高、损坏或权限错误，应立即停止，不要创建空库覆盖原文件；保留当前目录与备份，查看本地日志并进行人工排查。

## 8. 常见问题

- 页面打不开：确认终端中的服务仍在运行，地址是 `127.0.0.1` 且端口一致。
- 导入失败：确认格式是 SRT/VTT、编码为 UTF-8、大小不超过 10 MB、cue 不超过 20,000 条。
- 千问不可用：本地功能仍可继续；检查云端开关、同意状态、Keychain、网络、模型和 API 地址，不要反复自动重试。
- IPA 未命中：页面显示“本地未收录”，不会自动联网。
- TTS 不可用：检查 macOS 是否有英语语音；失败不会回退到云端语音。
- 上次位置失效：字幕被删除或复习队列变化后，应用会保留仍有效的位置；全部失效时安全返回字幕库。
