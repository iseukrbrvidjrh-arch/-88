# SceneLingo — 影视英语智能学习系统

## 项目立项报告 V1.0

**项目编号：** Project 001
**立项日期：** 2026年10月29日
**项目性质：** 个人英语学习 + AI辅助软件工程实践
**目标平台：** macOS
**开发模式：** Claude Code（DeepSeek）+ Codex CLI
**项目原则：** 本地优先、低成本、先完成再完善

---

## 一、项目背景

本项目旨在解决两个核心问题：

**第一，建立可持续的英语学习系统。**

通过影视字幕学习真实英语表达，结合词汇提取、中英文翻译、音标、语音朗读、AI对话和间隔复习，形成长期英语学习机制。

**第二，通过真实项目掌握软件工程思维。**

在AI辅助编程过程中，系统学习需求分析、软件架构、前端、后端、数据库、API、测试、Git版本管理及软件维护等知识。

本项目第一阶段仅供个人使用，不以商业化为目标。

## 二、产品功能

### 2.1 字幕管理

- 支持SRT、VTT格式。

- 解析字幕时间轴及英文句子。

- 统计词次、去重词汇量。

- 保留原始字幕与学习记录的关联。

### 2.2 英语学习

- 中英文翻译。

- 单词音标IPA。

- 英文单词、句子朗读。

- 单词释义及语境解释。

- 拼写、词义回忆和英文表达练习。

- 间隔复习和掌握状态管理。

### 2.3 AI英语导师

使用千问API提供聊天窗口，支持：

- 自由问答。

- 英语语法解释。

- 单词及短语比较。

- 重新造句。

- 英文短文生成。

- 英文表达纠错。

- AI生成内容经用户确认后加入学习库。

### 2.4 个人学习数据

- 词汇总量与去重词汇量。

- 已掌握、学习中、待学习词汇。

- 每日学习记录。

- 单词复习历史。

- 学习统计与进度分析。

## 三、技术架构

采用简单的模块化本地应用架构。

| 技术层  | 技术选型                 |
| ---- | -------------------- |
| 前端   | HTML、CSS、JavaScript  |
| 后端   | Python、FastAPI       |
| 数据库  | SQLite               |
| AI模型 | 千问API                |
| 语音   | macOS本地语音，后续可扩展Piper |
| 音标   | 本地发音词典，必要时使用音素转换     |
| 测试   | pytest               |
| 版本管理 | Git                  |
| 项目文档 | Markdown             |

千问API仅在用户主动调用时发送必要的学习内容。字幕和个人学习记录默认保存在本地。

模型调用层应独立设计，便于将来切换本地模型。

## 四、双AI协作机制

### Claude Code + DeepSeek

担任需求分析师及系统架构师。

负责：

1. 需求分析。

2. 软件架构设计。

3. 数据库设计。

4. API接口契约。

5. 模块拆分。

6. 开发任务卡。

7. 阶段性设计审查。

8. 软件工程知识讲解。

默认不负责修改应用代码。

### Codex CLI

担任开发工程师及测试工程师。

负责：

1. 编写前端代码。

2. 编写Python后端。

3. 实现数据库操作。

4. 接入千问API。

5. 实现字幕与英语学习功能。

6. 编写和运行自动化测试。

7. 修复程序错误。

8. 输出开发和测试记录。

### 用户

担任项目负责人及最终验收人。

负责确认需求、判断优先级、批准重要变更，并通过实际操作验证软件成果。

两个Agent通过同一Git仓库内的Markdown文档与任务卡协作，原则上不同时修改相同文件。

## 五、软件工程学习目标

项目按以下知识体系推进：

1. 计算机、操作系统与终端基础。

2. 软件开发生命周期与需求分析。

3. 系统架构与模块化设计。

4. 前端界面及事件交互。

5. Python后端和HTTP API。

6. 数据库及SQL。

7. 大语言模型API与上下文管理。

8. Git版本控制。

9. 软件测试、错误处理与安全。

10. 软件运行维护与迭代。

每个阶段必须同时完成工程功能验收和个人知识理解验收。

## 七、质量和安全要求

- 使用Git记录重要版本变更。

- 核心功能必须具备自动化测试。

- 不得伪造测试结果。

- API密钥不得提交到Git仓库。

- 本地服务默认只监听127.0.0.1。

- 未经许可不得上传个人文档或完整字幕文件。

- 设计方案有缺陷时必须提出变更建议。

- 词汇掌握度必须通过跨日期复习验证，不能简单以单日答对三次作为掌握依据。

- 软件工程学习不得完全挤占实际英语学习时间。

## 八、项目验收标准

### 产品验收

能够完成：

导入字幕 → 浏览字幕 → 翻译与解释 → 单词学习 → AI聊天 → 复习测试 → 保存进度 → 下次继续学习。

### 工程验收

关键功能通过测试，数据库持久化正确，程序能够在Mac本地重复启动。

### 学习验收

项目负责人能够解释各核心模块的职责、文件位置、数据流和基本验证方法。

### 英语学习验收

正式使用前建立英语能力基线，使用期间持续记录，并在后续独立测评中检查真实学习进步。

## 九、立项结论

批准启动SceneLingo个人版项目。

当前优先级：

**P0：建立共享本地Git仓库，初始化双Agent协作规则。**

暂不开发商业化系统，不增加与英语学习目标无关的复杂功能。

项目核心原则：

**英语学习是目的，软件工程是能力，AI是工具，实际效果是标准。**
