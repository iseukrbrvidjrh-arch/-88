## 1. 引言

### 1.1 目的

本文档为 SceneLingo 个人版建立可验证的需求基线，供以下角色使用：

- **用户 / 项目负责人**：确认需求范围、优先级和验收标准。
- **Claude Code（需求与架构）**：据此开展系统架构、数据库和 API 设计。
- **Codex CLI（实现与测试）**：据此编写任务卡、实现功能和设计测试。
- **未来的维护者（仍是用户本人）**：理解系统为什么这样设计，以及变更会影响什么。

### 1.2 范围

本文档覆盖 SceneLingo 第一阶段个人版从字幕导入到复习记录保存的完整学习闭环，包括：

- 字幕导入、解析、统计和语境保留；
- 翻译、释义、语境解释；
- IPA 音标、单词与句子朗读；
- 词汇候选、学习库、词条状态；
- 拼写、词义回忆、英文表达练习；
- 间隔复习与跨日期掌握判定；
- 千问 API 英语聊天及内容确认保存；
- 每日记录、复习历史和进度恢复；
- 本地运行、隐私、安全和可维护性要求；
- MVP 边界、异常处理、数据边界和验收追踪。

本文档不包含：

- 系统架构、模块划分、数据库表结构、API 契约；
- 前端页面视觉稿、后端实现方案、部署方案；
- 应用代码、测试代码；
- 商业化、多用户、云同步、移动端等后续能力的具体设计。

### 1.6 文档约定

#### 1.6.1 需求措辞

- **必须 / 应（MUST）**：MVP 验收必需；未满足即不能验收。
- **应当（SHOULD）**：推荐满足；若推迟，必须记录理由并获用户批准。
- **可以（MAY）**：可选能力，不影响 MVP 验收。
- **不得（MUST NOT）**：明确禁止，属于范围或安全边界。

#### 1.6.2 优先级

| 优先级 | 含义 | 处理规则 |
| --- | --- | --- |
| P0 | MVP 必须 | 不通过则 MVP 不能验收 |
| P1 | MVP 可选 / 后续优先 | 需用户明确批准才纳入 MVP；未批准可推迟 |
| P2 | 后续版本 | 当前不设计、不实现、不验收 |
| OUT | 明确不做 | 当前阶段排除，避免范围蔓延 |

#### 1.6.3 需求来源标记

为避免把技术建议误当作用户需求，每条功能需求标注来源：

## 2. 项目目标与成功标准

### 2.1 项目背景

SceneLingo 要解决两个问题：

1. **英语学习问题**：用真实影视字幕积累词汇、理解语境，并通过主动回忆和间隔复习形成长期记忆。
2. **软件工程学习问题**：通过一个真实、可运行、可验收的个人项目，学习需求、架构、前后端、数据库、API、测试、Git 和维护。

项目第一阶段仅供个人使用，不以商业化为目标；本地优先、低成本、先完成再完善。

### 2.2 项目目标

| 编号 | 目标 | 说明 |
| --- | --- | --- |
| G-01 | 建立可持续的影视英语学习闭环 | 导入字幕 → 浏览语境 → 理解与朗读 → 积累词条 → 主动回忆 → 间隔复习 → 记录与继续 |
| G-02 | 让学习数据可控、可解释 | 字幕和学习记录默认本地保存；用户知道哪些内容会发送到云端 |
| G-03 | 用真实项目完成软件工程实践 | 需求、设计、实现、测试、验收、维护均有文档和可验证产物 |
| G-04 | 控制范围与成本 | 不自动调用付费 API；不增加与英语学习目标无关的复杂功能 |

### 2.3 成功标准

| 编号 | 成功标准 | 验证方式 |
| --- | --- | --- |
| SC-01 | 用户能从一份有效英文字幕开始，完成“导入 → 浏览 → 翻译/解释 → 加词 → 朗读 → AI 辅助 → 复习 → 保存 → 下次继续”的完整闭环 | 端到端验收场景 AT-001 至 AT-013 |
| SC-02 | 应用重启、复习中断、导入失败后，已有数据不丢失、不重复、不静默损坏 | AT-003、AT-008、AT-013；检查持久化结果 |
| SC-03 | 词条“已掌握”必须由跨日期复习证据支持；同一天答对三次不能直接判为掌握 | AT-009；使用可控日期测试数据 |
| SC-04 | 没有用户主动操作时，不产生任何千问 API 请求；每次云端请求发送的内容与用户预览一致 | AT-010、AT-011；网络抓包或请求日志检查 |
| SC-05 | 所有 P0 功能需求通过对应验收条件；测试记录真实、可复现，不伪造结果 | 测试报告、验收记录、用户抽查 |
| SC-06 | 正式使用前建立英语能力基线；持续使用不少于 4 周；结束时用同类型、不同内容的独立测评复测，并如实记录结果 | 基线记录、使用记录、复测记录；不预设提升幅度 |
| SC-07 | 用户能够解释各核心模块的职责、文件位置、关键数据流和基本验证方法 | 每阶段认知验收问答与演示 |
| SC-08 | 文档、测试和数据边界足以支持后续维护；API Key 不进入仓库、日志或界面明文 | 文档检查、仓库扫描、日志检查、界面检查 |

> SC-06 的“4 周”是建议的过程标准，不是对学习效果的承诺；具体测评工具和指标由用户在 P7 前确认（OI-13）。

### 2.4 非目标

当前阶段明确不以以下事项为目标：

- 商业化、付费、多用户、社交、排行榜、打卡竞争；
- 云端账号、跨设备同步、移动端 App；
- 视频播放器、字幕下载、OCR、语音识别、发音评分；
- 自动批量翻译整部字幕、自动把整部字幕发送给云端；
- 自动生成学习计划并替代用户判断；
- 用软件功能数量或使用时长冒充英语学习成效；
- 让 AI 自动修改学习记录、自动判定掌握或自动保存内容。

## 3. 用户角色与真实使用场景

### 3.1 用户角色

| 角色 | 说明 | 主要目标 | 关键权限 |
| --- | --- | --- | --- |
| 学习者（唯一人类用户，同时是项目负责人） | 使用 macOS 的英语学习者；用影视字幕积累真实表达 | 看懂、记住、会用；持续学习 | 导入字幕、加词、复习、调用 AI、确认保存、验收 |
| 千问 API（外部系统） | 仅在被用户主动调用时提供语言辅助 | 返回翻译、解释、改写、纠错等文本 | 只接收用户预览并确认的最小内容 |
| macOS 本地语音（外部能力） | 提供英文朗读 | 朗读单词和句子 | 不接收云端数据 |
| 本地发音词典（外部数据） | 提供 IPA 和基础释义 | 离线查词 | 不联网 |

> 本项目没有管理员、教师、家长、访客或多用户角色。开发角色 Claude Code 与 Codex CLI 不是应用使用者。

### 3.2 使用环境与前提

- 平台：macOS 个人电脑。
- 使用方式：本地启动，浏览器访问本机页面。
- 网络：核心学习功能不依赖网络；AI 和云端翻译按需使用网络。
- 语言：界面使用简体中文；学习材料为英文；解释默认中文。
- 数据：字幕和个人学习数据默认保存在本地。
- 用户能力：能够阅读英文句子，能够判断 AI 回答是否合理；不要求用户会编程。

### 3.3 真实使用场景

| 编号 | 场景 | 用户想完成的事 | 关键约束 |
| --- | --- | --- | --- |
| S-01 | 周末导入新一集字幕 | 把刚下载的 SRT/VTT 导入，看看这集有多少词、哪些值得学 | 不自动翻译、不自动上传 |
| S-02 | 工作日晚上 20–30 分钟学习 | 打开上次的位置，逐句看，遇到生词加进学习库，听发音 | 可中断、可继续 |
| S-03 | 看剧时遇到一句不懂 | 选中该句，按需翻译或解释，结合上下文理解 | 只发送选中的句子；发送前可见 |
| S-04 | 想弄清一个词的用法 | 查释义、音标，听单词和例句；问 AI 近义词区别或造句 | 结果可保存，但必须确认 |
| S-05 | 睡前 10 分钟复习 | 复习今天到期的词，先回忆再看答案，系统安排下次日期 | 同一天答对不算多日掌握 |
| S-06 | 出差或没网 | 复习已学词、浏览字幕、听本地语音 | 不因云端不可用而阻塞 |
| S-07 | 学习被打断 | 关掉页面或电脑，第二天继续 | 每次作答已保存，不重复计分 |
| S-08 | 想确认 AI 是否可靠 | 看 AI 回答的来源标识和免责声明，自行判断后再决定是否保存 | AI 内容不自动进入学习库 |

### 3.4 用户故事

| 编号 | 用户故事 | 关联需求 |
| --- | --- | --- |

## 4. 完整软件使用流程

### 4.1 首次使用流程

1. 用户在本机启动 SceneLingo。
2. 系统显示本地数据说明和云端数据边界说明；用户可选择暂不配置千问 API Key。
3. 用户导入一份英文 `.srt` 或 `.vtt` 字幕。
4. 系统校验文件、解析字幕条目、清洗文本、统计词次和去重词汇量。
5. 若存在无效条目，系统导入有效条目并报告跳过数量；若全部无效，拒绝导入且不创建字幕记录。
6. 用户在字幕库中打开该字幕，按时间轴浏览台词。
7. 用户选中一条台词，按需请求翻译或语境解释；系统先展示将发送的内容，用户确认后才可能调用千问 API。
8. 用户点击单词查看释义、音标，播放单词或句子朗读。
9. 用户把想学的词加入学习库；词条状态为“待学习”，并保留来源台词。
10. 用户可与 AI 聊天；AI 回答只有经过选择、预览、确认后才保存到学习库。
11. 用户开始复习；系统按到期队列提供拼写和词义回忆。
12. 每次作答立即保存；用户可随时停止。
13. 系统记录每日学习活动和复习历史；用户下次打开时可继续上次位置。

### 4.2 日常学习流程

```text
打开应用
  → 查看今日到期数 / 继续上次字幕
  → 选择：先复习 或 先学新词
  → 复习：拼写 / 词义回忆 → 评分 → 自动安排下次日期
  → 学新词：浏览 cue → 按需翻译/解释 → 朗读 → 加入学习库
  → 需要时问 AI → 预览发送内容 → 确认发送 → 选择保存
  → 结束：查看今日记录 → 关闭
```

### 4.3 复习流程

1. 系统计算今日到期词条：待学习词条、学习中到期词条、已掌握但到期词条。
2. 用户选择复习模式：拼写、词义回忆或混合。
3. 系统逐条呈现题目。
4. 用户作答或自评。
5. 系统显示答案/释义，记录本次尝试。
6. 用户确认评分（记得 / 模糊 / 忘记）；拼写结果可作为默认评分的依据，但用户可调整。
7. 系统计算下次复习日期，立即保存。
8. 系统根据跨日期规则更新状态（待学习 / 学习中 / 已掌握）。
9. 用户可随时停止；未完成队列保留到下次。
10. 会话结束显示本次复习摘要（P1）。

### 4.4 AI 辅助流程

1. 用户从全局、词条详情或当前 cue 打开 AI 聊天。
2. 系统预填可选的上下文（当前词、当前句），但默认不附加相邻 cue，也不自动携带之前的历史消息。
3. 用户输入问题或选择任务类型；如需对话连贯，可显式开启“携带最近 N 条”，默认关闭。
4. 系统显示“本次将发送”的完整文本、附件数量、历史消息数量和目的地。
5. 用户可移除附件、关闭历史携带、编辑问题或取消。
6. 用户点击发送后，系统调用千问 API。
7. 系统显示 AI 回答，并标注“AI 生成，可能不准确”。
8. 用户可选择回答中的文字，选择保存类型（单词 / 短语 / 句子 / 笔记），预览后确认保存。
9. 取消保存则不产生学习条目；保存不会自动改变词条状态或复习计划。
10. 会话历史保存在本地，用户可删除会话；删除会话不删除已保存条目。

### 4.5 中断与恢复流程

- 导入中断：不产生半份字幕；已有数据不变。
- 复习中断：最后一次已确认的作答已保存；重启后剩余队列继续。
- AI 请求中断：不自动保存；未完成回答标注为“未完成”，用户可重试。
- 应用异常退出：重启后从本地已保存状态恢复；不得静默清空数据。
- 用户主动取消云端请求：丢弃本次未确认结果，不产生学习条目。

### 4.6 领域数据流（概念，不是架构设计）

```text
字幕文件
  → 解析后的字幕与 cue
  → 词形提取与统计（词次 / 去重词汇量）
  → 词汇候选列表
  → 用户确认加入学习库
  → 学习条目（词条 + 语境）
  → 复习尝试（拼写 / 词义回忆 / 表达练习）
  → 下次复习日期与掌握状态
  → 每日记录、复习历史、统计

AI 回答
  → 用户选择文本
  → 选择保存类型并确认
  → 学习条目（单词/短语）或参考资料（句子/笔记）
```

### 4.7 状态转换

#### 4.7.1 词条状态

```text
加入学习库 → 待学习
待学习 --第一次复习尝试--> 学习中
学习中 --满足跨日期掌握规则--> 已掌握
已掌握 --后续复习失败（模糊/忘记）--> 学习中
学习中 / 已掌握 --用户归档（P1）--> 已归档
已归档 --用户恢复（P1）--> 学习中（按历史重新计算）
```

- 不允许用户手动把词条直接设为“已掌握”。
- “已掌握”仍会按较长间隔进入复习；不是永久移除。

#### 4.7.2 AI 内容状态

```text
AI 生成
  → 用户浏览
  → 选择文本
  → 选择保存类型
  → 预览
  → 确认保存 / 取消
```

- 未确认的内容不进入学习库。
- 保存后的条目独立于聊天记录；删除聊天不删除已保存条目。

#### 4.7.3 字幕状态

```text
导入 → 已导入（可浏览）
已导入 --用户归档--> 已归档（默认，可恢复）
已导入/已归档 --用户确认硬删除--> 已删除（无关联记录，或已冻结语境快照）
已归档 --用户恢复--> 已导入
```

- 默认优先归档，不直接硬删除。
- 有关联词条/复习记录时，硬删除必须由用户确认；可选择保留冻结语境快照，不得静默级联删除学习记录。
- 原文件默认不复制进应用，只保存解析内容、时间轴和来源元数据（OI-07 已批准）。

### 4.8 流程规则

1. 任何步骤都不得因为云端不可用而阻塞本地核心学习。
2. 任何云端调用都必须由用户主动触发，并在发送前展示发送内容；默认不发送会话历史，历史携带需用户显式开启。
3. 任何词条加入学习库都必须由用户确认，导入字幕不自动加词。
4. 任何 AI 内容保存都必须由用户确认，AI 不自动写入学习库。
5. 任何掌握状态变化都必须有复习记录支持，不得由 AI 或用户手动直接设定。
6. 每次作答、每次导入、每次保存都应立即可恢复；不得只在会话结束时统一保存。
7. 用户可随时停止复习、取消 AI 请求、关闭页面；系统应保留已确认的数据。
8. 字幕归档/删除不得静默级联删除词条或复习历史；有关联记录时保留冻结语境快照或阻止硬删除。

## 5. 功能需求

> 说明：每条 FR 的“验收条件”是可测试的通过条件。业务细节见第 6 节；异常处理见第 9 节；云端边界见第 10 节。

### 5.1 系统与本地运行

#### FR-001 单用户本地运行与访问限制

- **优先级**：P0
- **来源**：U-00 §3、§7；U-RM §3
- **需求**：系统应作为单用户本地应用在 macOS 上运行，不要求注册、登录或账号体系；本地服务仅监听 `127.0.0.1`，局域网其他设备不能访问。
- **验收条件**：
  - AC-FR-001-1：在目标 macOS 上启动后，用户可通过本机地址打开界面并完成一次字幕导入，无需登录。
  - AC-FR-001-2：使用同一局域网内另一台设备访问本机局域网 IP 的同一端口，连接失败或不可用。
  - AC-FR-001-3：应用不提供用户注册、登录、多用户切换入口。

#### FR-002 离线核心能力

- **优先级**：P0
- **来源**：U-00 §2、§7；D
- **需求**：在无互联网连接时，用户仍可完成字幕导入与浏览、词汇候选与学习库、词条详情、IPA（本地词典有条目时）、单词/句子朗读、复习和记录查看。依赖云端的翻译、语境解释和 AI 聊天应明确显示不可用，而不是阻塞本地功能。
- **验收条件**：
  - AC-FR-002-1：断开网络后，导入有效 SRT、浏览 cue、加入词条、播放本地语音、完成一次复习并重启，全部成功。
  - AC-FR-002-2：断开网络后请求云端翻译或 AI 聊天，界面显示“需要网络/未配置密钥”等可操作提示，不出现无限加载。
  - AC-FR-002-3：离线期间已保存的本地数据在恢复网络后仍然存在。

#### FR-003 本地数据持久化

- **优先级**：P0
- **来源**：U-00 §2.5、§7；D
- **需求**：字幕、cue、词条、复习尝试、每日记录、AI 会话和设置应持久化在本地；应用重启后数据保持一致。
- **验收条件**：
  - AC-FR-003-1：导入字幕后重启应用，字幕、cue、统计和词条仍可查看。
  - AC-FR-003-2：完成复习后重启应用，复习历史、下次复习日期和词条状态不变。
  - AC-FR-003-3：重启前后同一条字幕的词次和去重词汇量一致。

### 5.2 字幕导入、解析与浏览

#### FR-010 SRT 字幕导入

- **优先级**：P0
- **来源**：U-00 §2.1
- **需求**：系统应支持导入标准 `.srt` 英文字幕，解析时间轴和文本；解析规则见 BR-SUB-03。
- **验收条件**：
  - AC-FR-010-1：导入一份含 3 条有效 cue 的标准 SRT，字幕库新增 1 条记录，cue 数量、时间轴和文本与文件一致。
  - AC-FR-010-2：扩展名为 `.srt` 但内容不是有效 SRT 时，系统拒绝导入并给出原因，不创建字幕记录。

#### FR-011 VTT 字幕导入

- **优先级**：P0
- **来源**：U-00 §2.1
- **需求**：系统应支持导入标准 `.vtt` 英文字幕；解析规则见 BR-SUB-04。
- **验收条件**：
  - AC-FR-011-1：导入含 `WEBVTT` 头、`NOTE` 块和 2 条有效 cue 的 VTT，仅 2 条 cue 被导入，`NOTE` 内容不显示为台词。
  - AC-FR-011-2：VTT 时间轴、文本和顺序与文件一致；无效 VTT 被拒绝且不创建记录。

#### FR-012 字幕文本清洗与解析

- **优先级**：P0
- **来源**：U-00 §2.1；D
- **需求**：系统应清洗字幕文本：去除格式标签、解码常见 HTML 实体、保留可读文本和时间轴；无效 cue 按 BR-SUB-06 处理。
- **验收条件**：
  - AC-FR-012-1：含 `<i>Hello</i>` 的 cue 显示为 `Hello`，不显示标签。
  - AC-FR-012-2：`&amp;` 等常见实体显示为对应字符；换行和标点按 BR-SUB-05 保留或合并。
  - AC-FR-012-3：时间轴无效的 cue 被跳过并计入报告；有效 cue 不受影响。

#### FR-013 字幕库与字幕浏览

- **优先级**：P0
- **来源**：U-00 §2.1、§8；U-RM §2.1
- **需求**：系统应提供字幕库，显示每份字幕的名称、导入时间、cue 数、词次和去重词汇量；用户可打开字幕，按时间顺序浏览 cue 的时间轴和文本。本阶段不播放视频。
- **验收条件**：
  - AC-FR-013-1：导入两份字幕后，字幕库显示两条记录及各自统计。
  - AC-FR-013-2：打开字幕后可按顺序浏览全部 cue，显示时间轴和文本；界面无视频播放功能。
  - AC-FR-013-3：关闭并重新打开字幕后，仍能定位到上次浏览的 cue（与 FR-082 联动）。

#### FR-014 导入校验与部分无效处理

- **优先级**：P0
- **来源**：D
- **需求**：导入前应校验文件格式、编码、大小和 cue 有效性；部分无效时导入有效条目并报告跳过数量；全部无效时拒绝，不创建半份字幕。
- **验收条件**：
  - AC-FR-014-1：含 2 条有效、1 条无效 cue 的文件导入后，字幕库有 2 条 cue，并显示“跳过 1 条”的报告。
  - AC-FR-014-2：全部 cue 无效时，导入失败，字幕库不新增记录，已有数据不变。
  - AC-FR-014-3：文件过大或编码不支持时，导入被拒绝并给出可操作提示。

#### FR-015 重复导入识别

- **优先级**：P0
- **来源**：D
- **需求**：系统应识别内容相同的重复字幕；默认不重复导入，并提示已存在。MVP 不提供“作为新副本导入”；如后续提供，必须单独批准并警告统计会重复计算。
- **验收条件**：
  - AC-FR-015-1：再次导入内容相同的字幕，系统提示已存在，默认不新增记录。
  - AC-FR-015-2：用户取消后，字幕库数量不变。
  - AC-FR-015-3：MVP 界面不存在“作为新副本导入”入口；副本导入作为 P1，不作为 MVP 验收项。

#### FR-016 词次与去重词汇统计

- **优先级**：P0
- **来源**：U-00 §2.1；D
- **需求**：系统应统计每份字幕及全库的词次和去重词汇量，规则见 BR-SUB-08；统计结果应可重复计算且一致。
- **验收条件**：
  - AC-FR-016-1：使用含有已知 token 的固定测试字幕，词次和去重词汇量与预期完全一致。
  - AC-FR-016-2：重复打开或重启后，同一字幕的统计结果不变。
  - AC-FR-016-3：全库统计等于各字幕词次之和；全库去重词汇量为跨字幕去重后的并集。

#### FR-017 语境关联与上下文保留

- **优先级**：P0
- **来源**：U-00 §2.1；U-RM §2.1
- **需求**：每个词条/学习条目应保留其来源字幕、cue 序号、时间轴和原文；用户查看词条时能回到语境。
- **验收条件**：
  - AC-FR-017-1：从某条 cue 加入词条后，词条详情显示该 cue 的原文和时间轴。
  - AC-FR-017-2：点击来源可定位到字幕中的对应 cue。
  - AC-FR-017-3：重启后语境关联仍存在。

#### FR-018 字幕归档与删除

- **优先级**：P0
- **来源**：U-00 §2.1、§2.5；D
- **需求**：系统应允许用户归档字幕（默认隐藏、可恢复）和在受控条件下删除字幕；不得因删除字幕而静默删除词条、复习历史或语境引用。
- **验收条件**：
  - AC-FR-018-1：归档字幕后，该字幕从默认字幕库隐藏，可通过“已归档”筛选找到并恢复；关联词条和历史不受影响。
  - AC-FR-018-2：无关联词条/复习记录的字幕可硬删除；确认后字幕消失，统计更新，不产生错误引用。
  - AC-FR-018-3：存在关联词条/复习记录时，硬删除默认被阻止并说明原因；用户只能归档，或明确确认“删除字幕但保留冻结语境快照”。
  - AC-FR-018-4：选择冻结快照后，词条详情仍显示原 cue 文本、字幕标题和“来源已删除”标记；复习历史仍可打开。
  - AC-FR-018-5：取消归档/删除后数据不变；任何路径都不得静默级联删除学习记录。

### 5.3 翻译、释义与语境解释

#### FR-020 单句按需翻译

- **优先级**：P0
- **来源**：U-00 §2.2；U-RM §2.2
- **需求**：用户选中一条 cue 并主动请求时，系统应提供英译中翻译；句子翻译优先按需调用千问 API，成功结果本地缓存；一次请求只针对该 cue，不做整部字幕批量翻译。
- **验收条件**：
  - AC-FR-020-1：选中一条 cue 请求翻译，发送预览只包含该 cue 的文本。
  - AC-FR-020-2：确认后显示中文翻译，并标明来源（本地缓存/千问 API）；没有缓存时才发起云端请求。
  - AC-FR-020-3：未选中的其他 cue 不出现在发送内容中；不存在“一键翻译整部字幕”入口。

#### FR-021 单词释义

- **优先级**：P0
- **来源**：U-00 §2.2；U-RM §2.2
- **需求**：单词详情应提供中文释义；本地词典优先并支持离线；本地未命中时明确显示“本地未收录”，用户可主动请求千问释义，发送前必须预览确认；不得静默调用云端或伪造释义。
- **验收条件**：
  - AC-FR-021-1：查询词典中存在的单词，显示中文释义和来源，不发起网络请求。
  - AC-FR-021-2：断网时，词典中存在的单词仍显示释义。
  - AC-FR-021-3：词典中不存在的单词显示“本地未收录”，不显示空白或编造内容，也不自动调用云端。
  - AC-FR-021-4：用户主动请求 AI 释义时，预览只含该词和用户选择的语境；结果标注 AI 来源并可缓存。

#### FR-022 语境解释

- **优先级**：P0
- **来源**：U-RM §2.2；`docs/00` §2.4；2026-10-29 用户批准
- **需求**：用户可请求结合当前 cue 的语境解释，用中文说明该单词或句子在此语境中的含义；按需调用千问 API，结果本地缓存，并标记为辅助解释/AI 生成。
- **验收条件**：
  - AC-FR-022-1：从一条 cue 请求语境解释，发送预览包含该词和该 cue，不包含整部字幕。
  - AC-FR-022-2：结果明确标注“语境解释”、AI 来源和时间；用户确认后才可能保存为笔记。
  - AC-FR-022-3：取消请求不产生结果或学习条目。
  - AC-FR-022-4：选中文本、悬停或切换 cue 不触发请求；只有用户明确点击并确认后才请求。
  - AC-FR-022-5：超时、限流、拒绝或网络失败时保留原文并显示可操作错误，不把失败缓存为成功。

#### FR-023 翻译/解释缓存与来源标识

- **优先级**：P0
- **来源**：D；U-00 §2.5 本地优先
- **需求**：翻译、释义和语境解释结果应本地缓存，并显示来源（本地词典/本地缓存/千问 API）和时间；重复相同请求优先使用缓存。
- **验收条件**：
  - AC-FR-023-1：同一 cue 的翻译第二次请求时显示“本地缓存”，不再产生云端请求。
  - AC-FR-023-2：结果旁显示来源和时间；用户可区分本地与云端结果。
  - AC-FR-023-3：清除缓存后再次请求可重新获取；清除缓存不影响词条和复习记录。

#### FR-024 云端发送预览与确认

- **优先级**：P0
- **来源**：U-00 §2.5、§7；U-RM §3；D
- **需求**：任何发送到千问 API 的请求必须在发送前显示将发送的完整文本、上下文和目的地，并由用户点击发送确认；首次使用需同意数据边界说明。
- **验收条件**：
  - AC-FR-024-1：首次请求云端翻译时，显示数据边界说明；未同意前不发送请求。
  - AC-FR-024-2：每次发送前可查看完整发送文本；取消则不发送。
  - AC-FR-024-3：发送内容与预览一致，不额外附带整部字幕、学习记录或密钥。

#### FR-025 云端失败降级

- **优先级**：P0
- **来源**：D；U-00 §7
- **需求**：云端不可用或失败时，显示可操作的错误信息；不保存伪造结果；本地功能继续可用；重试由用户主动触发。
- **验收条件**：
  - AC-FR-025-1：未配置 Key、断网、超时、限流或服务错误时，显示对应提示，不出现“成功”假象。
  - AC-FR-025-2：失败后不创建翻译/解释记录，不改变学习数据。
  - AC-FR-025-3：失败后仍可浏览字幕、加词、复习和使用本地语音。

### 5.4 音标

#### FR-030 单词 IPA 查询与显示

- **优先级**：P0
- **来源**：U-00 §2.2；U-RM §2.2
- **需求**：单词详情应显示 IPA 音标，标注口音和来源；优先使用本地发音词典，规则见 BR-IPA。
- **验收条件**：
  - AC-FR-030-1：查询词典中存在的单词，显示 IPA 和口音/来源标识。
  - AC-FR-030-2：断网时，词典中存在的单词仍显示 IPA。
  - AC-FR-030-3：同一单词在词条详情和复习界面显示的 IPA 一致。

#### FR-031 未知词与音标缺失处理

- **优先级**：P0
- **来源**：D；U-00 §3“必要时使用音素转换”
- **需求**：本地词典无该词时显示“暂无音标”，不得静默调用云端；用户可在 AI 聊天中另行询问，但需经过发送预览与确认。
- **验收条件**：
  - AC-FR-031-1：查询不存在的词，显示“暂无音标”，且不产生网络请求。
  - AC-FR-031-2：用户主动在 AI 聊天中询问该词发音时，发送前可见发送内容。
  - AC-FR-031-3：音标缺失不影响该词的加入、朗读（TTS 可读文本）和拼写复习。

### 5.5 朗读

#### FR-040 单词朗读

- **优先级**：P0

- **需求**：用户点击单词时，系统应使用 macOS 本地英语语音朗读该词；不得自动播放。
- **验收条件**：
  - AC-FR-040-1：点击单词播放英文发音；再次点击可重播。
  - AC-FR-040-2：断网时仍可播放。
  - AC-FR-040-3：打开页面或切换词条时不自动播放。

#### FR-041 句子朗读

- **优先级**：P0
- **来源**：U-00 §2.2；U-RM §2.2
- **需求**：用户点击 cue 时，系统应朗读清洗后的整句英文，不朗读格式标签。
- **验收条件**：
  - AC-FR-041-1：点击 cue 播放完整句子；不含 `<i>` 等标签。
  - AC-FR-041-2：多行 cue 按 BR-SUB-05 合并为可朗读句子。
  - AC-FR-041-3：断网时仍可播放。

#### FR-042 播放控制与失败处理

- **优先级**：P0
- **来源**：D
- **需求**：系统应提供停止和重播；语音不可用或失败时给出提示，不回退云端；不录音、不做发音评分。
- **验收条件**：
  - AC-FR-042-1：播放中可停止；停止后可重播。
  - AC-FR-042-2：系统无可用英语语音时，显示可操作提示，不自动调用云端 TTS。
  - AC-FR-042-3：界面不存在录音、发音评分或麦克风权限入口。

### 5.6 词汇与学习库

#### FR-050 词汇候选列表

- **优先级**：P0
- **来源**：U-00 §2.1；D
- **需求**：字幕解析后应生成词汇候选列表，显示去重词形、出现次数、首次出现 cue 和是否已在学习库；不得自动加入学习库。
- **验收条件**：
  - AC-FR-050-1：候选列表包含该字幕的所有有效词形，按 BR-SUB-08 去重。
  - AC-FR-050-2：每项显示出现次数和首次出现 cue；已在学习库的项有标识。
  - AC-FR-050-3：导入字幕后学习库词条数不自动增加。

#### FR-051 加入学习库

- **优先级**：P0
- **来源**：U-00 §2.1、§2.3；U-RM §2.2
- **需求**：用户可将候选词加入学习库；加入后状态为“待学习”，并关联当前 cue。重复加入不得创建重复词条。
- **验收条件**：
  - AC-FR-051-1：点击“加入学习库”后，词条出现在学习库，状态为“待学习”，带来源 cue。
  - AC-FR-051-2：再次加入同一词形，不新增词条；语境按 BR-VOC-06 合并。
  - AC-FR-051-3：未点击加入时，学习库不增加词条。

#### FR-052 一词多语境

- **优先级**：P0
- **来源**：U-00 §2.1；D
- **需求**：同一词形从不同 cue 加入时，应保留多个语境示例，词条仍唯一。
- **验收条件**：
  - AC-FR-052-1：从两条不同 cue 加入同一词，学习库仍只有 1 个词条，详情显示 2 条语境。
  - AC-FR-052-2：重复添加完全相同的 cue，不产生重复语境。
  - AC-FR-052-3：每个语境显示来源字幕和时间轴。

#### FR-053 学习库浏览、筛选与排序

- **优先级**：P0
- **来源**：U-00 §2.3；U-RM §2.4
- **需求**：学习库应支持按状态筛选、按词形搜索、按词次/字母/加入时间排序。
- **验收条件**：
  - AC-FR-053-1：按“学习中”筛选，只显示该状态词条。
  - AC-FR-053-2：搜索词形（大小写不敏感）返回匹配词条。
  - AC-FR-053-3：三种排序结果稳定且可重复。

#### FR-054 词汇状态管理

- **优先级**：P0
- **来源**：U-00 §2.3；U-RM §2.4；D
- **需求**：词条状态应为“待学习 / 学习中 / 已掌握”；状态转换按 BR-VOC-05 和 BR-REV-05；不允许用户手动直接设为“已掌握”。
- **验收条件**：
  - AC-FR-054-1：新词条为“待学习”；首次复习后为“学习中”。
  - AC-FR-054-2：满足跨日期规则后自动变为“已掌握”；不提供手动设为“已掌握”的按钮。
  - AC-FR-054-3：已掌握词条复习失败后回到“学习中”。

#### FR-055 词形规范化与去重

- **优先级**：P0
- **来源**：D
- **需求**：词形规范化按 BR-VOC-03；大小写、弯引号等差异不得产生重复词条；显示形式保留首次出现形式。
- **验收条件**：
  - AC-FR-055-1：`Don't`、`don't`、`DON’T` 视为同一词条。
  - AC-FR-055-2：`well-known` 与 `well known` 是否合并由 BR-VOC-03 明确定义，测试结果与规则一致。
  - AC-FR-055-3：重复加入不产生第二个词条。

#### FR-056 词条详情

- **优先级**：P0
- **来源**：U-00 §2.2、§2.3；U-RM §2.2
- **需求**：词条详情应显示词形、音标、释义、来源语境、状态、下次复习日期和复习历史摘要。
- **验收条件**：
  - AC-FR-056-1：词条详情包含上述字段；缺失项显示“暂无”，不显示空白错位。
  - AC-FR-056-2：从详情可跳转到来源 cue。
  - AC-FR-056-3：复习后详情中的状态和下次日期更新。

#### FR-057 词条归档/移出学习库（P1 候选）

- **优先级**：P1（需用户批准）
- **来源**：D，立项报告未明确要求
- **需求**：用户可将词条归档或移出学习库；归档后不再进入复习队列，历史保留；可恢复。
- **验收条件**：
  - AC-FR-057-1：归档后该词条不出现在复习队列，学习库状态显示“已归档”。
  - AC-FR-057-2：复习历史仍可查看。
  - AC-FR-057-3：恢复后按历史重新计算状态，不伪造掌握。

### 5.7 练习与复习

#### FR-060 复习队列

- **优先级**：P0
- **来源**：U-00 §2.3；U-RM §2.2；D
- **需求**：复习队列应显示今日到期词条，包括待学习、学习中到期和已掌握但到期词条；排序规则见 BR-REV-01；用户可随时停止。
- **验收条件**：
  - AC-FR-060-1：到期词条出现在队列；未到期词条不出现（已掌握但到期除外）。
  - AC-FR-060-2：待学习词条首次出现；复习后按新日期消失或重新出现。
  - AC-FR-060-3：用户停止后，未完成队列保留，下次可继续。

#### FR-061 拼写练习

- **优先级**：P0
- **来源**：U-00 §2.3；U-RM §2.2
- **需求**：拼写练习应显示中文释义和挖空目标词的语境 cue，用户输入英文词；判定规则见 BR-REV-03；记录作答结果。
- **验收条件**：
  - AC-FR-061-1：题目隐藏目标词，显示释义和挖空语境；提交前不显示答案。
  - AC-FR-061-2：大小写、首尾空格、弯引号差异不影响判定；拼写错误记录为错误并显示正确答案。
  - AC-FR-061-3：每次提交产生一条复习尝试记录。

#### FR-062 词义回忆

- **优先级**：P0
- **来源**：U-00 §2.3；U-RM §2.2；D
- **需求**：词义回忆应显示英文词和语境，用户先自评是否记得，再显示释义；记录自评，不进行自动语义评分。
- **验收条件**：
  - AC-FR-062-1：显示词和语境时不同时显示释义；用户点击后才显示释义。
  - AC-FR-062-2：自评“记得/模糊/忘记”被记录；系统不根据自由文本自动判分。
  - AC-FR-062-3：无释义的词条不进入词义回忆，提示先获取释义。

#### FR-063 英文表达练习（P1 候选）

- **优先级**：P1（需用户批准）
- **来源**：U-RM §2.2；`docs/00` 未明确列出
- **需求**：系统可给出目标词/语境，用户写英文句子；保存尝试；可选请求 AI 纠错；表达练习不单独计入掌握。
- **验收条件**：
  - AC-FR-063-1：用户提交句子后保存为表达尝试，显示提交时间。
  - AC-FR-063-2：不自动判定对错；如请求 AI 纠错，需经过发送预览与确认。
  - AC-FR-063-3：仅完成表达练习不会让词条变为“已掌握”。

#### FR-064 复习评分与下次复习日期

- **优先级**：P0
- **来源**：U-00 §2.3；D
- **需求**：每次复习后按 BR-REV-04 计算下次复习日期；评分包括“记得 / 模糊 / 忘记”；结果立即保存。
- **验收条件**：
  - AC-FR-064-1：三种评分分别产生规则规定的下次日期。
  - AC-FR-064-2：刷新或重启后，下次日期和状态不变。
  - AC-FR-064-3：拼写结果提供默认评分；拼写正确时可下调为“模糊/忘记”，拼写错误时可上调为“模糊”但不能改为“记得”；最终记录以用户确认为准。

#### FR-065 掌握状态判定

- **优先级**：P0
- **来源**：U-00 §2.3、§7；D
- **需求**：掌握判定按 BR-REV-05；必须跨日期验证；同一天多次正确只算一个日期；后续失败应回退。
- **验收条件**：
  - AC-FR-065-1：同一天答对 3 次，词条仍为“学习中”。
  - AC-FR-065-2：在 3 个不同日期成功，且至少一次成功距首次成功不少于 7 天，最近一次成功，则变为“已掌握”。
  - AC-FR-065-3：已掌握后出现“模糊”或“忘记”，立即回到“学习中”，下次复习为 1 天后。

#### FR-066 复习历史

- **优先级**：P0
- **来源**：U-00 §2.3；U-RM §2.4
- **需求**：复习历史应按时间倒序显示每次尝试：词条、模式、日期时间、答案/自评、正确性、间隔变化；历史不可编辑。
- **验收条件**：
  - AC-FR-066-1：每次复习后历史新增一条记录，字段完整。
  - AC-FR-066-2：界面不提供编辑或删除单条历史的功能。
  - AC-FR-066-3：按词条和日期筛选结果正确。

#### FR-067 复习中断与即时保存

- **优先级**：P0
- **来源**：U-00 §8；D
- **需求**：复习过程中每次作答应立即保存；刷新、关闭或重启后可继续剩余队列；不得重复计分。
- **验收条件**：
  - AC-FR-067-1：完成 3 题后刷新页面，前 3 题记录存在，队列从第 4 题继续。
  - AC-FR-067-2：重启应用后复习历史和下次日期一致。
  - AC-FR-067-3：同一题不会因刷新被重复写入两条记录。

#### FR-068 复习会话总结（P1 候选）

- **优先级**：P1（需用户批准）
- **来源**：D
- **需求**：复习会话结束时可显示本次复习数、正确数、正确率和状态变化；用户可关闭。
- **验收条件**：
  - AC-FR-068-1：完成 5 题后摘要显示 5 次尝试及正确数。
  - AC-FR-068-2：摘要数字与复习历史一致。
  - AC-FR-068-3：关闭摘要不改变任何记录。

### 5.8 AI 英语导师

#### FR-070 AI 聊天窗口

- **优先级**：P0
- **来源**：U-00 §2.4；U-RM §2.3
- **需求**：系统应提供 AI 聊天窗口，可从全局、词条详情或当前 cue 打开；消息和会话历史保存在本地。
- **验收条件**：
  - AC-FR-070-1：从词条详情打开聊天，窗口显示该词为可选上下文。
  - AC-FR-070-2：发送一条消息并收到回答后，会话出现在本地历史。
  - AC-FR-070-3：重启后历史仍可查看。

#### FR-071 AI 任务类型

- **优先级**：P0（短语比较子项 P1）
- **来源**：U-00 §2.4；U-RM §2.3；2026-10-29 用户批准
- **需求**：系统应支持以下 AI 任务：
  - P0：语法解释、重新造句、英文短文生成、英文表达纠错、自由问答；
  - P1（需用户批准）：单词/短语比较。
- **验收条件**：
  - AC-FR-071-1：P0 任务均有明确入口或提示模板；自由问答可接收用户自由输入；回答与任务相关。
  - AC-FR-071-2：短语比较未获批准时，不显示为 MVP 必需功能，也不作为验收项。
  - AC-FR-071-3：所有任务均遵守发送预览、用户主动触发和确认保存规则。
  - AC-FR-071-4：自由问答不绕过上下文选择、云端同意和密钥检查。
  - AC-FR-071-5：请求失败或用户取消时不产生半条 AI 消息、不写入学习库、不计为成功复习。

#### FR-072 上下文选择与发送预览

- **优先级**：P0
- **来源**：U-00 §2.5；D
- **需求**：发送前用户可选择或移除上下文附件（当前 cue、词/短语、可选相邻 cue）；预览应显示完整发送内容；默认不附带相邻 cue，也默认不发送之前的历史消息。用户可显式开启“携带最近 N 条”，默认关闭。
- **验收条件**：
  - AC-FR-072-1：默认只包含用户输入和显式选择的词/cue，不包含相邻 cue，也不包含之前的历史消息。
  - AC-FR-072-2：移除附件后，预览和实际发送均不含该内容。
  - AC-FR-072-3：相邻 cue 只有在用户主动添加时才发送，并在预览中可见。
  - AC-FR-072-4：开启“携带最近 N 条”后，预览显示具体条数和内容，请求只含这 N 条；关闭时请求不含历史。
  - AC-FR-072-5：开始新会话后，不自动携带旧会话消息；旧会话内容只能由用户显式重新添加。

#### FR-073 仅用户主动调用

- **优先级**：P0
- **来源**：U-00 §2.4、§2.5；U-RM §3；D
- **需求**：只有用户点击发送才调用千问 API；打开窗口、输入、滚动、导入字幕、浏览、复习均不得触发云端调用。
- **验收条件**：
  - AC-FR-073-1：启动、导入、浏览、复习期间无千问 API 请求。
  - AC-FR-073-2：输入文字但未点击发送，不产生请求。
  - AC-FR-073-3：取消发送不产生请求。

#### FR-074 AI 响应展示与标识

- **优先级**：P0
- **来源**：D
- **需求**：AI 响应应显示“AI 生成”标识；失败或不完整响应不得显示为成功；用户可取消等待。
- **验收条件**：
  - AC-FR-074-1：每条 AI 回答带有 AI 标识和免责声明。
  - AC-FR-074-2：请求失败显示错误，不显示空白成功消息。
  - AC-FR-074-3：等待中可取消；取消后不保存为完成回答。

#### FR-075 AI 内容确认后保存

- **优先级**：P0
- **来源**：U-00 §2.4；U-RM §2.3
- **需求**：AI 内容只有在用户选择文本、选择保存类型、预览并确认后才保存；取消不保存；保存不得自动改变词条状态或复习计划。
- **验收条件**：
  - AC-FR-075-1：未点击保存时，学习库不增加条目。
  - AC-FR-075-2：点击保存后出现类型选择和预览；确认后条目出现，并标注来源为 AI。
  - AC-FR-075-3：保存单词条目后，其状态仍为“待学习”，不自动变为“学习中”或“已掌握”。

#### FR-076 AI 会话历史管理

- **优先级**：P0
- **来源**：D
- **需求**：AI 会话历史应本地保存，支持查看和删除；删除会话不删除已保存的学习条目。
- **验收条件**：
  - AC-FR-076-1：历史列表显示会话标题/时间和消息。
  - AC-FR-076-2：删除会话后，该会话消失。
  - AC-FR-076-3：已保存的学习条目仍存在，且不指向已删除会话作为唯一来源。

#### FR-077 AI 服务异常处理

- **优先级**：P0
- **来源**：D
- **需求**：AI 服务异常（无密钥、离线、超时、限流、内容拒绝、响应异常）应显示分类错误；不自动循环重试；本地功能不受影响。
- **验收条件**：
  - AC-FR-077-1：缺少密钥时显示配置说明，不发起请求。
  - AC-FR-077-2：断网、超时、限流分别显示可区分提示。
  - AC-FR-077-3：失败后不自动重复发送；用户可手动重试。

#### FR-078 API 密钥配置与保护

- **优先级**：P0
- **来源**：U-00 §3、§7；U-RM §7
- **需求**：千问 API Key 只能由用户在本地配置；界面掩码显示；不得写入 Git、日志或提示词；缺失时给出配置说明。
- **验收条件**：
  - AC-FR-078-1：界面只显示掩码，不显示完整 Key。
  - AC-FR-078-2：仓库、日志、错误信息和发送预览中不出现完整 Key。
  - AC-FR-078-3：未配置 Key 时，云端功能禁用并显示设置指引。

### 5.9 学习记录与进度

#### FR-080 每日学习记录

- **优先级**：P0
- **来源**：U-00 §2.3；U-RM §2.4；D
- **需求**：系统应记录每日学习活动：日期、复习次数、正确次数、新增词条数、表达练习次数（P1）和 AI 内容保存数；判定规则见 BR-REC-01。
- **验收条件**：
  - AC-FR-080-1：完成复习和加词后，当天记录显示对应计数。
  - AC-FR-080-2：仅打开应用或导入字幕，不产生“学习日”记录。
  - AC-FR-080-3：跨日期后，记录按本地日期分列，不合并。

#### FR-081 词汇状态统计

- **优先级**：P0
- **来源**：U-00 §2.3；U-RM §2.4
- **需求**：系统应统计学习库词条总数、待学习/学习中/已掌握数量、今日到期数和归档数（P1）；统计应与记录一致。
- **验收条件**：
  - AC-FR-081-1：三种状态数量之和等于未归档词条总数。
  - AC-FR-081-2：复习和状态变化后，统计立即更新。
  - AC-FR-081-3：重启后统计与本地数据记录一致。

#### FR-082 学习进度与继续学习

- **优先级**：P0
- **来源**：U-00 §8；U-RM §2.4
- **需求**：系统应记住最近打开的字幕、cue 和未完成复习队列；重启后提供“继续学习”，一次操作恢复。
- **验收条件**：
  - AC-FR-082-1：关闭应用后重新打开，首页显示“继续学习”入口。
  - AC-FR-082-2：点击后回到上次字幕和 cue；未完成复习队列可继续。
  - AC-FR-082-3：若上次数据已不存在，系统回到字幕库并提示，不崩溃。

### 5.10 设置与云端控制

#### FR-090 云端同意与关闭

- **优先级**：P0
- **来源**：U-00 §2.5、§7；D
- **需求**：首次云端调用前应显示数据边界说明并要求同意；用户可在设置中关闭云端功能；关闭后不发生任何千问调用，缓存结果仍可查看。
- **验收条件**：
  - AC-FR-090-1：首次调用前出现说明；拒绝后不发送。
  - AC-FR-090-2：关闭云端后，翻译/AI 入口显示不可用，无请求产生。
  - AC-FR-090-3：关闭云端不影响本地字幕、词条、复习和本地缓存查看。

#### FR-091 千问模型配置与经济型模型

- **优先级**：P0
- **来源**：U-00 §2.4、§7；2026-10-29 用户批准
- **需求**：系统应允许用户配置千问模型，默认使用经济型模型；模型不可用时给出明确错误，不得静默切换到更昂贵模型。
- **验收条件**：
  - AC-FR-091-1：设置中显示可用模型和当前模型；默认经济型；选择后重启仍保持。
  - AC-FR-091-2：未配置 Key、模型不可用或模型 ID 无效时，显示明确错误，不发起调用。
  - AC-FR-091-3：经济型模型失败时不静默升级；如提供切换，必须由用户确认。
  - AC-FR-091-4：每次调用记录实际模型标识，可与费用记录对应。

#### FR-092 千问调用费用记录与估算

- **优先级**：P0
- **来源**：U-00 §7；2026-10-29 用户批准
- **需求**：系统应记录每次用户主动发起的千问调用及费用估算，至少包括时间、用途、模型、输入/输出用量（若可获得）、估算费用、币种和价格版本；无法精确时明确标注“估算”，不得伪装为账单。
- **验收条件**：
  - AC-FR-092-1：每次成功调用产生一条费用记录；字段完整。
  - AC-FR-092-2：无法获得 token 用量时标注“按字符估算”及方法，不显示为精确账单。
  - AC-FR-092-3：按日/按会话汇总等于对应记录之和；刷新、重启后仍可查看。
  - AC-FR-092-4：失败/取消调用如产生供应商计费，记录实际或估算费用；未产生计费则不虚增，不重复计数。
  - AC-FR-092-5：启动、导入、浏览、复习等非用户主动调用不产生费用记录。

## 6. 业务规则

> 业务规则用于把模糊的用户愿望变成可执行、可测试的规则。V0.2 中除明确标注“待验证”的外部依赖外，规则已随 SRS 一并批准；实现不得把未验证事项写成已满足。

### 6.1 字幕导入与解析规则（BR-SUB）

#### BR-SUB-01 支持格式

- MVP 支持 `.srt` 和 `.vtt` 两种扩展名；文件内容必须与格式匹配。
- 不支持 ASS/SSA、SUB、IDX、纯文本等格式；遇到时拒绝并列出支持格式。
- 本阶段只处理英文字幕；中英双语字幕按英文文本处理，中文字符保留在显示文本中但不计入英文词汇统计。
- 双语字幕的朗读、翻译和统计仅以英文部分为验收对象；中文部分保留显示，不作为 MVP 质量验收项。

#### BR-SUB-02 编码

- MVP 支持 UTF-8（含 BOM）编码。
- 非 UTF-8 编码不得静默转码；系统应拒绝并提示用户另存为 UTF-8。
- 若后续需要支持 UTF-16 或 Windows-1252，需另行确认（OI-08）。

#### BR-SUB-03 SRT 解析

- cue 之间以空行分隔。
- 序号行可选；若存在，必须为整数，但不要求连续。
- 时间轴格式：`HH:MM:SS,mmm --> HH:MM:SS,mmm`；允许小时为 1–3 位。
- 起始时间必须早于结束时间；时间不得为负。
- 文本行为时间轴之后直到空行的内容；可多行。
- 缺少时间轴、时间倒置或文本为空的 cue 视为无效。

#### BR-SUB-04 VTT 解析

- 文件应以 `WEBVTT` 开头；允许头部元数据。
- `NOTE`、`STYLE`、`REGION` 块不显示为台词，不参与统计。
- cue 时间轴使用 `.` 作为毫秒分隔符；允许 `HH:MM:SS.mmm` 或 `MM:SS.mmm`。
- cue 可带标识符和显示设置；标识符和设置不显示为台词。
- 文本行解析规则与 SRT 相同。

#### BR-SUB-05 文本清洗

- 去除 HTML/字幕格式标签，如 `<i>`、`<b>`、`<font ...>`、VTT 内联标签；保留标签内的文字。
- 解码常见 HTML 实体，如 `&amp;`、`&quot;`、`&#39;`。
- 去除行首行尾空白；保留句内标点、大小写和撇号。
- 多行 cue 在显示时保留换行；用于翻译和朗读时以单个空格合并。
- 方括号 `[...]` 内的音效/音乐说明保留在显示文本中，但不参与词汇统计（见 BR-SUB-08）。
- 花括号样式标签（如 `{\an8}`）去除。
- 全大写说话人标签（行首、2–20 个大写字母或空格、后接冒号，如 `JOHN:`）保留在显示文本中，但不参与词汇统计。

#### BR-SUB-06 无效 cue 处理

- 单条 cue 无效时跳过，并在导入报告中记录行号和原因。
- 若至少有一条有效 cue，导入成功，显示“有效 N 条，跳过 M 条”。
- 若没有有效 cue，导入失败，不创建字幕记录，不写入任何 cue。
- 重叠时间轴允许存在；按文件顺序保留，不自动合并。
- 完全重复的 cue 保留，因为可能对应不同画面/语境；统计按出现次数计算。

#### BR-SUB-07 大小与数量限制（已批准为护栏，待真实样本验证）

- 单文件最大 10 MB。
- 单文件最多 20,000 条 cue。
- 超过限制时拒绝导入，提示用户拆分或检查文件。
- 该限制用于防止误导入超大文件导致界面无响应；具体阈值需在目标 Mac 上用真实样本验证，验证后可调整并记录。

#### BR-SUB-08 词次、去重词汇量与词形规范化

**词形（token）定义：**

- 连续英文字母 `A-Z a-z`，可包含词内撇号（`'` 或 `’`）和连字符（`-`）。
- 去除词首词尾的撇号/连字符。
- 包含数字的字符串整体不计入（如 `1999`、`MP3`、`B2B`）。
- 非拉丁文字不计入英文词次。
- 长度至少 2 个字母，或为单词 `a` / `i`。
- 缩略形式（contraction）按一个词形处理：`don't`、`it's`、`I'm`、`can't`；`it's` 与 `its` 是两个不同词形。
- 所有格保留：`John's` 与 `John` 是两个不同词形；`teacher's` 同理。
- 连字符复合词按一个词形处理：`well-known`；空格形式 `well known` 为两个词形，不自动合并。
- 不做词形还原（lemmatization）：`run`、`runs`、`running`、`ran` 分别统计。该口径已随 V0.2 批准；如后续改为 lemma，需单独变更。
- 停用词（如 `the`、`a`、`to`）计入统计，不自动排除；候选列表可按频率排序，但不得静默删除。
- 方括号 `[...]` 内的内容和全大写说话人标签不计入统计。
- 弯撇号 `’` 规范为直撇号 `'`；大小写不敏感。
- 显示形式保留首次出现时的形式；去重键为小写规范形式。

**带点缩写（MVP 的明确规则）：**

- 句点作为词形分隔符；单字母片段除 `a` / `i` 外不计入。
- 因此 `U.S.` 拆成单字母后不计入；`Mr.` 会贡献 `mr`；`e.g.` / `i.e.` 的片段按同一规则处理。
- 这是可复现但有噪声的规则；MVP 不引入命名实体识别或完整缩写词典。
- 如用户不接受 `mr` 等噪声，可在 P1 增加一个小型“非学习词”排除表；不得用云端 NLP 擅自清洗。

**统计定义：**

- 单字幕词次：该字幕所有有效 cue 中所有词形出现次数之和。
- 单字幕去重词汇量：该字幕所有词形的去重键数量。
- 全库词次：各字幕词次之和。
- 全库去重词汇量：跨字幕所有词形去重键的并集数量。
- 学习库词条数与字幕去重词汇量是两个不同指标，不得混用。

**示例：**

| cue | 文本 | 计入词形 | 词次数 |
| --- | --- | --- | --- |
| 1 | `I don't think it's well-known.` | `i`, `don't`, `think`, `it's`, `well-known` | 5 |
| 2 | `Don't go! 1999` | `don't`, `go` | 2 |
| 3 | `[MUSIC] JOHN: Hello...` | `hello`（`[MUSIC]` 和 `JOHN:` 不计） | 1 |
| 4 | `Mr. Smith's U.S. trip` | `mr`, `smith's`, `trip`；`u.s.` 拆成单字母后不计 | 3 |

四 cue 示例合计词次 11，去重词汇量 10（`i`, `don't`, `think`, `it's`, `well-known`, `go`, `hello`, `mr`, `smith's`, `trip`）。

#### BR-SUB-09 语境关联

- 每个 cue 保存：所属字幕、顺序号、开始时间、结束时间、显示文本、清洗后句子文本。
- 学习条目保存来源 cue 的引用；字幕归档后引用仍可读，字幕硬删除时按 FR-018 保留冻结语境快照或阻止删除。
- 冻结语境快照至少保存：原 cue 文本、字幕标题、cue 时间轴；不要求保留整部字幕。
- 同一词条可有多个语境；每个语境对应一条来源 cue。

#### BR-SUB-10 重复导入

- 内容相同指解析后的 cue 时间轴与文本集合相同；文件名相同但内容不同不算重复。
- MVP 默认行为：提示已存在，不导入，保留原记录。
- MVP 不提供“作为新副本导入”；该能力保留 P1，需用户批准后新增需求。
- 即使未来提供副本导入，副本与原件也不自动合并词条或复习记录。

#### BR-SUB-11 浏览与定位

- 字幕按 cue 顺序显示时间轴和文本。
- 用户点击来源语境时，定位到对应 cue；若 cue 不存在，显示“来源已不可用”。
- 本阶段不提供视频同步播放。

#### BR-SUB-12 字幕归档与删除

- 归档是默认操作：字幕从默认列表隐藏，可恢复；不删除 cue、词条或复习历史。
- 无关联词条/复习记录的字幕可硬删除；删除前必须二次确认。
- 有关联记录时，默认阻止硬删除，并说明关联数量；用户只能归档，或明确确认“删除字幕并保留冻结语境快照”。
- 不得静默级联删除词条、复习历史或笔记。
- 原始字幕文件默认不复制；应用只保存解析后的内容和元数据。

### 6.2 翻译、释义与语境解释规则（BR-TRL）

#### BR-TRL-01 翻译单位

- 翻译以单条 cue 为单位；一次用户请求只处理一条 cue。
- 不提供整部字幕批量翻译；不在导入时自动翻译。

#### BR-TRL-02 语言方向

- MVP 只支持英文到简体中文的翻译和解释。
- 用户在 AI 聊天中可要求英文示例，但界面语言和解释默认中文。

#### BR-TRL-03 单词释义与单句翻译的来源

**单词释义（本地优先）：**

- 优先使用本地词典提供中文释义和词性（若词典有）。
- 本地词典无释义时，显示“本地未收录”，不自动调用云端，也不伪造释义。
- 用户可主动请求千问释义；发送前必须经过 FR-024/FR-072 的预览与确认，结果写入本地缓存。
- 释义不是学习事实的最终裁决；用户可自行判断。

**单句翻译（千问优先）：**

- 用户对单条 cue 请求翻译时，按需调用千问 API；成功结果缓存。
- 缓存命中时不重复调用，并显示“本地缓存”。
- 不在导入时自动翻译，不批量翻译整部字幕。

#### BR-TRL-04 语境解释（P0）

- 语境解释按需调用千问 API，属于 P0；结果本地缓存并标记 AI 来源。
- 输入为：目标单词/短语/句子 + 当前 cue 文本；默认不包含相邻 cue，也不默认携带历史消息。
- 输出为中文解释，说明该词/句在当前语境中的含义，可包含例句。
- 结果标记为“语境解释（AI 辅助）”，不自动写入词条释义。
- 用户可将其保存为笔记；保存需确认。

#### BR-TRL-05 缓存与来源

- 成功结果按“类型 + 源文本 + 语境 + 目标语言”缓存到本地。
- 相同请求优先命中缓存，显示“本地缓存”，不产生云端请求。
- 用户可手动刷新；刷新会重新发送，需再次预览确认。
- 来源标识至少包括：本地词典、本地缓存、千问 API。

#### BR-TRL-06 发送边界

- 翻译请求只发送当前 cue 的清洗后文本。
- 单词释义请求只发送单词；若用户选择“结合语境”，再附加当前 cue。
- 不发送其他 cue、整部字幕或学习历史；密钥不得作为请求内容，只用于认证。

#### BR-TRL-07 失败与重试

- 无网络、无 Key、超时、限流、内容拒绝、响应无法解析时，显示分类错误。
- 不自动循环重试；用户可手动重试。
- 失败不产生缓存记录，不创建学习条目。

#### BR-TRL-08 结果标识

- 所有机器翻译和 AI 解释均标注来源和“可能需要人工判断”。
- 不把机器翻译显示为人工确认的权威释义。

### 6.3 词汇与学习库规则（BR-VOC）

#### BR-VOC-01 候选词汇

- 候选词汇来自字幕有效 cue 的词形统计，按 BR-SUB-08 去重。
- 每项显示：显示词形、去重键、出现次数、首次出现 cue、是否已在学习库。
- 默认按出现次数降序、同频按字母升序排列。
- 不自动排除停用词；用户可按需筛选（P1 可增加停用词开关）。

#### BR-VOC-02 显式加入

- 只有用户点击“加入学习库”或确认保存 AI 单词内容，才创建词条。
- 导入字幕、浏览候选列表、点击单词查看详情均不自动加入。
- 不加“全部加入”默认按钮；若后续提供批量加入，必须二次确认（P1）。

#### BR-VOC-03 规范化与去重

- 去重键：小写、弯撇号转直撇号、去除首尾空白、保留词内撇号和连字符。
- `well-known` 与 `well known` 在 MVP 中视为两个不同词形；不自动合并。该口径随 V0.2 批准。
- 显示形式保留首次加入时的形式；后续同键加入不改变显示形式。
- 一个去重键对应一个词条；不同词条不得共享同一去重键。

#### BR-VOC-04 词条字段

词条至少包含：

- 显示词形、去重键；
- 来源（字幕/AI）；
- 语境列表（cue 原文、时间轴、字幕标识）；
- 状态（待学习/学习中/已掌握/已归档）；
- 释义（本地词典或用户确认的 AI 释义）；
- IPA（若有）；
- 创建时间、更新时间；
- 下次复习日期；
- 复习历史摘要。

#### BR-VOC-05 状态转换

- 新建：待学习。
- 首次复习尝试后：学习中。
- 满足 BR-REV-05：已掌握。
- 已掌握后复习失败：学习中。
- 用户归档（P1）：已归档；不进入复习队列。
- 恢复归档（P1）：按历史重新计算为学习中或已掌握，不得直接伪造掌握。
- 不提供手动“设为已掌握”。

#### BR-VOC-06 多语境

- 同一词条从不同 cue 加入时，追加语境；完全相同的 cue 不重复追加。
- 语境按加入顺序或时间轴排序，界面可切换。
- 语境数量不设硬上限，但界面应分页或折叠，避免性能问题。

#### BR-VOC-07 学习库浏览

- 支持按状态筛选、按词形搜索、按词次/字母/加入时间排序。
- 搜索大小写不敏感，支持部分匹配。
- 已归档词条默认不出现在主列表，可通过“已归档”筛选查看（P1）。

#### BR-VOC-08 AI 内容保存类型

- **单词**：单个词形；加入学习库，可复习。
- **短语**：多个词；作为参考资料保存，MVP 不自动进入复习（P1 是否复习待定，OI-16）。
- **句子**：完整句子；作为参考资料保存。
- **笔记**：自由文本；可关联词条或 cue。
- 保存时用户必须选择类型；系统可根据文本给出建议，但不强制。

#### BR-VOC-09 参考资料与复习

- MVP 中只有“单词”类型进入复习队列。
- 短语、句子、笔记不自动安排复习；用户可在词条详情查看。
- 若后续要让短语进入复习，需新增需求并确认（OI-16）。

#### BR-VOC-10 归档与恢复（P1）

- 归档不删除历史；只从复习队列和默认列表移除。
- 恢复后按历史重新计算状态；历史中的成功/失败记录仍有效。
- 归档词条不计入“学习中/已掌握”统计，但计入“已归档”统计。

#### BR-VOC-11 统计口径

- 学习库词条数：未归档词条总数。
- 待学习/学习中/已掌握：按当前状态计数。
- 今日到期数：到期日期不晚于今天的未归档词条数。
- 字幕词次/去重词汇量：按 BR-SUB-08 独立计算，不与学习库词条数混用。

### 6.4 音标规则（BR-IPA）

#### BR-IPA-01 范围

- MVP 只提供单词级 IPA，不提供句子级音标。
- 不提供发音评分、口型分析或录音对比。

#### BR-IPA-02 口音与来源（美式优先已批准）

- MVP 默认显示美式 IPA（General American），并在界面标注口音。
- 若本地词典只有英式或其他口音，显示实际口音，不冒充美式。
- 每个音标显示来源（词典名称/版本）。
- 口音选择是否可配置保留 P1；OI-03 中尚未完成的词典许可与覆盖率验证不改变本方向，但验收前必须完成。

#### BR-IPA-03 查询顺序

1. 用去重键查询本地词典。
2. 若未命中且词形以 `'s` 结尾，尝试去掉 `'s` 的基础形式。
3. 仍未命中则显示“暂无音标”。
4. MVP 不自动做其他词形还原（如 `running` → `run`）；该限制已随 V0.2 批准；本地词形还原或音素转换保留 P1。

#### BR-IPA-04 云端边界

- 音标查询默认不调用云端。
- 本地词典缺失时，不得静默调用千问 API。
- 用户可在 AI 聊天中主动询问发音；该请求遵守第 10 节发送边界。

#### BR-IPA-05 显示

- 音标以 IPA 斜杠形式显示，如 `/wɜːrd/`；具体格式由界面设计决定。
- 音标缺失显示“暂无音标”，不显示空字符串。
- 同一词条在不同界面显示同一音标。

#### BR-IPA-06 许可与覆盖

- 本地词典的来源、许可、版本和覆盖率必须在实现前确认（OI-03）。
- 若词典许可不允许随应用分发，必须改为用户自行安装或使用允许分发的替代来源。
- 词典覆盖率不足时，应如实显示缺失，不得用 AI 结果冒充本地词典结果。

### 6.5 朗读规则（BR-TTS）

#### BR-TTS-01 本地语音

- 单词和句子朗读优先使用 macOS 本地英语 TTS。
- 默认不调用云端 TTS；后续是否支持 Piper 等本地引擎属于 P2/技术演进，不是 MVP 需求。

#### BR-TTS-02 朗读文本

- 单词：朗读显示词形。
- 句子：朗读清洗后的 cue 文本；多行以空格合并；不含标签、说话人标签或方括号说明（可保留标点）。
- 不朗读中文释义，除非未来新增双语朗读需求。

#### BR-TTS-03 触发与自动播放

- 只有用户点击播放按钮才朗读。
- 打开页面、切换 cue、进入复习题时不自动播放。
- 一次点击只朗读当前目标，不自动连续播放整个字幕。

#### BR-TTS-04 播放控制

- 提供停止和重播。
- 播放新目标时，应停止 previous 播放，避免重叠。
- 不要求变速、跟读、录音或发音评分；这些为 P2/OUT。

#### BR-TTS-05 失败处理

- 系统无英语语音、语音引擎错误或权限问题时，显示可操作提示。
- 不自动回退到云端 TTS。
- 朗读失败不影响词条、复习和字幕数据。

#### BR-TTS-06 默认声音

- MVP 使用系统默认英语语音，正常速度。
- 用户选择声音/速度保留 P1；MVP 使用系统默认英语语音和正常速度。

### 6.6 AI 聊天与内容保存规则（BR-AI）

#### BR-AI-01 用户主动

- 只有用户点击发送才调用千问 API。
- 不做自动问候、自动总结、自动翻译、自动生成学习计划。
- 不做后台定时调用。

#### BR-AI-02 任务类型

P0：

- 语法解释：解释句子/短语的语法结构和用法。
- 重新造句：基于目标词/句生成替代表达（这是 AI 生成任务，不是用户表达练习）。
- 英文短文生成：按用户主题/词表生成英文短文。
- 英文表达纠错：对用户英文进行纠错并解释。
- 自由问答：用户可自由输入问题并获得回答。

P1（保留）：

- 单词/短语比较。

说明：自由问答的入口、提示模板和回答质量纳入 MVP 验收。FR-063 的“用户英文表达练习”仍是独立的 P1 功能，不能被“重新造句”替代或偷偷纳入 P0。

#### BR-AI-03 上下文

- 可选附件：当前 cue 文本、选中单词/短语、用户主动添加的相邻 cue。
- 默认不附加相邻 cue、其他字幕、整部字幕、学习历史或复习记录。
- 默认不发送同一会话的先前消息。
- 用户可显式开启“携带最近 N 条消息”，默认关闭；开启后预览必须显示具体条数和内容，实际只发送这 N 条。
- 开始新会话时，不自动携带旧会话内容。

#### BR-AI-04 发送预览

- 发送前显示：用户消息、附件文本、会话历史消息数、目的地“千问 API”。
- 用户可移除附件、编辑消息、取消。
- 首次使用显示数据边界说明；用户同意后才可发送。
- 发送内容必须与预览一致；不得偷偷追加字幕或学习数据。

#### BR-AI-05 响应与标识

- 每条 AI 回答标注“AI 生成，可能不准确”。
- 失败、取消、未完成分别显示不同状态，不伪装成成功。
- 不自动把 AI 回答写入词条释义、笔记或学习库。

#### BR-AI-06 保存流程

1. 用户选择回答中的文本（或整条回答）。
2. 选择保存类型：单词/短语/句子/笔记。
3. 预览保存内容，可编辑。
4. 确认保存。
5. 系统创建学习条目，标注来源为 AI、保存时间和原始会话（若会话被删除，条目仍保留）。

#### BR-AI-07 保存约束

- 单词类型必须为单个词形；短语为多个词；句子含句末标点；笔记为自由文本。
- 单词加入学习库后状态为待学习；不自动复习、不自动掌握。
- 短语/句子/笔记在 MVP 中为参考资料，不进入复习（OI-16）。
- 重复保存同类型、同规范化文本时，提示合并/取消；默认不产生重复条目。
- 用户可在保存前编辑文本；保存后标注“AI 生成，经用户确认/编辑”。

#### BR-AI-08 会话历史

- 会话历史本地保存，至少包含：创建时间、消息角色、文本、时间、模型标识（若可获得）、错误状态。
- 用户可查看、删除单个会话或全部会话。
- 删除会话不删除已保存的学习条目。
- 会话保留期限默认“直到用户删除”；自动清理保留 P1。

#### BR-AI-09 异常

- 无 Key：禁用发送，显示配置说明。
- 离线：显示网络错误，不自动重试。
- 超时：显示超时，可手动重试；不自动循环。
- 限流/配额：显示限流/配额提示，不自动重试。
- 内容拒绝：显示服务拒绝原因（若可得），不尝试绕过。
- 响应格式异常：显示“响应无法解析”，不保存为成功回答。
- 流式中断：显示“未完成”，用户可重试；未完成内容不得标记为完整回答。

#### BR-AI-10 密钥与提示词

- API Key 不进入任何提示词、预览、日志或错误消息。
- 不在前端界面显示完整 Key。
- 用户可在本地更新/删除 Key；更新后旧 Key 不再使用。

#### BR-AI-11 不可信内容

- 字幕和用户输入可能包含指令性文本；AI 输出仍只作为内容展示，不自动执行任何操作。
- AI 不能自动加词、改状态、改复习计划、删除数据或调用其他云服务。
- 用户确认是唯一写入学习库的入口。

#### BR-AI-12 模型配置与经济型模型

- 用户可配置千问模型；默认使用经济型模型。
- 模型标识不得硬编码在无法修改的界面逻辑中；配置变更需用户确认。
- 模型不可用时显示错误并停止请求，不静默切换到更贵模型。
- 每次调用记录实际使用的模型标识。

#### BR-AI-13 费用记录与估算

- 每次用户主动发起的千问调用应记录：时间、用途、模型、输入/输出用量（若 API 返回）、估算费用、币种、价格版本。
- 若 API 不返回 usage，按字符数估算并明确标注“按字符估算”，不得冒充账单精确值。
- 当日/本次会话总计等于对应记录之和；失败或取消的调用只有实际计费时才记录，避免重复计数。
- 费用记录仅保存在本地，不上传云端。

### 6.7 复习与掌握规则（BR-REV）

#### BR-REV-01 复习队列

- 到期定义：`下次复习日期 ≤ 今天（本地日期）`。
- 队列包含：待学习词条、学习中到期词条、已掌握但到期词条。
- 排序：到期日期升序 → 状态（学习中优先于已掌握）→ 加入时间升序 → 词形字母升序。
- 用户可随时停止；未完成队列保留。
- MVP 不设每日新词硬上限；界面显示队列数量，用户自行决定学习量。该口径随 V0.2 批准。

#### BR-REV-02 复习模式

- 拼写模式：主动产出英文词形。
- 词义回忆模式：看到词和语境，自评是否记得，再揭示释义。
- 混合模式：两种模式交替出现（P1 可选；P0 至少提供两种独立模式）。
- 每次尝试记录模式。

#### BR-REV-03 拼写判定

- 题目显示中文释义和挖空目标词的语境；目标词所有出现处替换为 `____`。
- 用户输入后提交；系统按以下规则比较：
  - 去除首尾空白；
  - 大小写不敏感；
  - 弯撇号视为直撇号；
  - 连字符必须保留；
  - 不做拼写容错、不启用自动纠错。
- 完全匹配为正确；否则为错误，并显示正确词形。
- 拼写结果记录为“正确/错误”；默认评分：正确→记得，错误→忘记。
- 用户可在提交后调整评分：拼写正确时可下调为“模糊/忘记”；拼写错误时可上调为“模糊”，但不能改为“记得”。这样防止拼写错误被算作成功。
- 掌握判定中的“成功”以最终评分为准；但拼写错误的尝试即使被调整为“模糊”，也不计为成功。
- 每次提交生成一条复习尝试；不可编辑历史。

#### BR-REV-04 评分与下次日期

| 评分 | 含义 | 下次间隔 | 状态影响 |
| --- | --- | --- | --- |
| 记得（Good） | 主动回忆成功或拼写正确 | 首次成功为 1 天后；之后按 1→3→7→14→30 天序列推进；达到 30 后维持 30 天 | 计为一次成功；满足 BR-REV-05 则已掌握 |
| 模糊（Hard） | 有印象但不能确定 | 未掌握：`max(1, floor(当前间隔 / 2))` 天；无当前间隔时为 1 天。已掌握：1 天 | 不计成功；已掌握则回退学习中，下次为 1 天后 |
| 忘记（Again） | 无法回忆或拼写错误 | 1 天 | 间隔重置；已掌握则回退学习中 |

补充规则：

- “当前间隔”指该词条上一次安排的天数；首次复习没有当前间隔。
- 已掌握词条仍进入复习；MVP 最长间隔 30 天。
- 60/120/180 天长间隔保留 P1 实验，不得在未批准时替换 MVP 序列。
- 下次日期 = 本地日期 + 间隔天数。
- 用户可调整拼写默认评分；最终以用户确认的评分为准。
- 同一天多次复习都记录，但掌握判定按日期去重（见 BR-REV-05）。

#### BR-REV-05 掌握判定（已批准）

**“成功”的定义：** 词义回忆的最终评分为“记得”；或拼写模式的拼写正确且最终评分保持“记得”。拼写错误即使被上调为“模糊”，也不算成功。

词条变为“已掌握”必须同时满足：

1. 至少有 **3 次成功** 的主动回忆/拼写尝试；
2. 这 3 次成功发生在 **至少 3 个不同的本地日历日期**；
3. 至少有一次成功发生在距 **首次成功日期不少于 7 个日历日** 的日期；
4. **最近一次尝试是成功的**（按本节“成功”定义）；
5. 不存在手动把状态设为“已掌握”的操作。

补充：

- 同一天多次成功只算一个日期；“模糊”和“忘记”不算成功。
- 拼写正确但被用户下调为“模糊/忘记”的尝试，不算成功；以最终评分为准。
- 表达练习（P1）不计入成功次数。
- 已掌握后出现“模糊”或“忘记”，立即回到“学习中”，下次复习为 1 天后。
- 已掌握词条继续复习；后续成功不会重复“升级”，失败会回退。
- 测试时必须能控制日期，不接受“把系统时钟改来改去”作为唯一测试手段；实现应提供可测试的日期注入或等价测试机制（属于设计约束，不是界面功能）。

**示例：**

| 日期 | 尝试 | 结果 | 是否满足掌握 |
| --- | --- | --- | --- |
| 第 1 天 | 第 1 次 | 记得 | 否（仅 1 天） |
| 第 1 天 | 第 2 次 | 记得 | 否（同日不重复计日） |
| 第 1 天 | 第 3 次 | 记得 | 否（仍是 1 天） |
| 第 2 天 | 第 4 次 | 记得 | 否（2 天） |
| 第 8 天 | 第 5 次 | 记得 | 是（3 个日期，且距首次 7 天，最近成功） |

#### BR-REV-06 复习历史

- 每次尝试记录：词条、模式、本地日期时间、用户输入（拼写）、正确性、自评、评分、复习前间隔、复习后间隔、下次日期。
- 历史按时间倒序展示；不可编辑、不可删除单条。
- 删除全部本地数据属于独立隐私需求，仍待 OI-12 决定；不得通过删除单条历史绕过掌握判定。

#### BR-REV-07 即时保存

- 用户确认评分后立即保存；不得等会话结束。
- 刷新/关闭/崩溃后，已保存的尝试不得丢失或重复。
- 未确认的题目不产生记录。

#### BR-REV-08 中断与恢复

- 未完成队列保留；下次打开可继续。
- 已完成题目不再出现在队列，除非已到新日期。
- 不允许同一题因刷新重复计分。

#### BR-REV-09 会话总结（P1）

- 显示复习数、正确数、正确率、状态变化数量。
- 数字必须与历史记录一致；关闭不改变数据。

#### BR-REV-10 日期与时间

- 使用用户本地时区的日历日期；日界线为本地 00:00。
- 不提供手动修改复习日期的入口。
- 系统时钟大幅回拨/前进时，不得产生重复每日记录或负数间隔；具体处理待 OI-17。
- 未来日期不得被手动设置为“已复习”。

#### BR-REV-11 无定义词条

- 没有中文释义的词条可进行拼写复习，但不进入词义回忆；界面提示“暂无释义，先获取释义”。
- 没有 IPA 不影响复习。
- 没有语境不影响拼写，但词义回忆只显示词形和释义。

### 6.8 学习记录与统计规则（BR-REC）

#### BR-REC-01 学习事件

以下事件计入当日学习记录：

- 完成一次复习尝试（拼写或词义回忆）；
- 新增一个学习库词条；
- 完成一次英文表达练习（P1）；
- 确认保存一条 AI 学习内容。

以下不计入：

- 仅打开应用；
- 仅导入字幕；
- 仅浏览字幕或候选列表；
- 仅打开 AI 聊天但未保存内容；
- 仅播放语音。

#### BR-REC-02 每日记录字段

- 日期（本地日历日）；
- 复习次数、正确次数；
- 新增词条数；
- 表达练习次数（P1）；
- AI 内容保存数。
- 同一个 AI 单词保存事件可以同时增加“新增词条数”和“AI 内容保存数”，因为二者是不同指标；同一指标内不得重复计数。
- 不记录键盘输入内容、不记录学习时长（MVP 不做时长统计）。

#### BR-REC-03 统计定义

- 词次/去重词汇量：按 BR-SUB-08。
- 学习库词条数：未归档词条总数。
- 待学习/学习中/已掌握：按当前状态。
- 今日到期数：按 BR-REV-01。
- 正确率：正确尝试数 / 总尝试数；无尝试时显示“暂无”。正确尝试指拼写正确或词义回忆自评“记得”；“模糊”和“忘记”不计为正确。
- 统计必须由记录计算得出，不得手工填写。

#### BR-REC-04 复习历史

- 历史属于审计数据，不因词条归档而删除。
- 历史可用于统计和掌握判定。
- 用户删除全部数据属于独立操作，待 OI-12。

#### BR-REC-05 继续学习

- 保存最近打开的字幕 ID、cue ID、复习队列进度、最近学习时间。
- 重启后“继续学习”优先恢复最近上下文；若数据缺失，回到字幕库。
- 继续学习不得自动触发云端请求。

#### BR-REC-06 日期显示

- 界面按本地日期显示；跨时区旅行时以当前本地日期为准。
- 不把 UTC 日期直接显示给用户。
- 同一天内的多次事件合并到一条每日记录。

#### BR-REC-07 数据一致性

- 统计、状态和历史必须一致；变更后立即反映。
- 不允许用缓存统计覆盖真实记录；重算结果应可重复。
- 发现不一致时，以原始尝试记录为准重新计算，并记录修复日志（设计阶段决定实现方式）。

### 7.2 关键 NFR 的补充说明

#### NFR-001 性能说明

- 性能指标以参考设备为准；测试报告必须写明设备、系统版本、文件规模和测量方法。
- AI 响应时间受网络和供应商影响，不设固定上限；但界面必须显示等待状态、允许取消，并在超时后给出提示。
- 性能不达标时，不得通过减少功能或伪造数据“达标”；应记录实际结果并决定优化或调整目标。

#### NFR-005 隐私说明

- “无遥测”包括不接入第三方统计 SDK、不发送崩溃报告到外部服务、不自动检查更新并向外部发送设备信息。
- 本地日志可以记录错误码和数量，但不得记录完整字幕、完整聊天内容或 API Key。
- 云端请求的最小化规则见第 10 节。

#### NFR-006 安全说明

- 本地单用户不要求登录，但不得因此监听公网或局域网。
- 本地 HTTP 服务应校验请求来源或采用等效防护，拒绝非本应用页面的跨站调用；验收时从其他网页或非预期来源发起的请求应被拒绝。
- 文件导入必须限制类型和大小，防止误读任意路径；不得把用户输入的文件名直接当路径执行。
- API Key 的配置方式由架构阶段决定，但必须满足“不进仓库、不进日志、不明文显示”。

#### NFR-012 可测试性说明

- 测试不能只覆盖“正常导入一份字幕”；必须覆盖无效字幕、重复导入、离线、云端失败、复习中断和跨日期掌握。
- 掌握规则的测试必须使用可控日期，不能依赖真实等待 7 天。
- 测试结果必须如实记录失败项和未覆盖项。

## 8. MVP 功能边界

### 8.1 MVP 定义

SceneLingo MVP 是 P2–P6 交付的、可在 macOS 本地日常使用的个人版。它必须完成“字幕 → 理解 → 词条 → 复习 → 记录 → 继续”的核心闭环，并满足所有 P0 功能需求和对应 NFR。

MVP 不是“功能最多”的版本，而是“能真实用于英语学习并验证需求”的最小版本。

### 8.2 范围表

| 领域 | MVP 包含（P0） | MVP 可选（P1，需批准） | 不在 MVP（P2/OUT） |
| --- | --- | --- | --- |
| 运行 | 单用户、本地、127.0.0.1、离线核心功能 | 无 | 账号、多用户、云同步、移动端 |
| 字幕 | SRT/VTT 导入、解析、清洗、统计、浏览、语境关联、重复识别、归档/受控删除 | 原文件复制 | 视频播放、字幕下载、OCR、自动翻译整部 |
| 翻译/释义 | 单句按需翻译、单词释义、语境解释（P0）、缓存、发送预览、失败降级 | 批量释义管理 | 批量翻译、离线大模型翻译 |
| 音标 | 本地词典 IPA、缺失提示、口音标识 | 用户选择口音、G2P 补充 | 发音评分、录音对比 |
| 朗读 | 单词/句子本地 TTS、停止/重播 | 语速/声音选择 | 云端 TTS、跟读评分 |
| 词汇 | 候选列表、加词、多语境、详情、状态、搜索/筛选/排序 | 归档/恢复、批量加入 | 自动加词、词根词缀课程、词书市场 |
| 复习 | 拼写、词义回忆、评分、间隔、跨日期掌握、历史、即时保存、恢复 | 混合模式、会话总结、表达练习 | 社交打卡、排行榜、AI 自动判分 |
| AI | 聊天、P0 任务（含自由问答）、上下文预览、确认保存、历史、异常处理、密钥保护、模型配置、费用记录/估算 | 短语比较 | 自动批量生成、后台代理、自动改数据 |
| 记录 | 每日记录、状态统计、继续学习 | 趋势分析、导出/备份 | 云端报表、跨设备统计 |
| 数据 | 本地持久化、缓存、日志脱敏 | 备份/恢复、删除全部数据 | 云备份、多端同步 |
| 学习成效 | 基线/使用/复测的过程记录（P7） | 更细的分析 | 用使用时长冒充成效 |

### 8.3 MVP 退出标准

MVP 可进入验收，必须同时满足：

1. 所有 P0 FR 的 AC 通过；P1 未纳入的功能不作为阻塞项。
2. 所有标记为 P0 的端到端场景通过，至少覆盖 AT-001 至 AT-016、AT-019 语境解释、AT-020 性能基线、AT-022 字幕归档/删除、AT-023 AI 上下文与费用记录；P1 场景（AT-017/018/021）按是否纳入决定。
3. 无阻断级或严重级缺陷；已知缺陷有记录、影响说明和用户接受。
4. 隐私检查通过：无用户操作时无千问请求；发送内容与预览一致；密钥不入库/日志/界面明文。
5. 重启、刷新、导入失败、复习中断后数据一致。
6. 测试报告真实，包含失败项、限制和未覆盖项。
7. 用户完成产品验收和认知验收；P7 学习成效验收另行进行。

### 8.4 范围变更规则

- 新增 P0 功能、把 P1 提升为 P0、改变数据边界或掌握规则，必须由用户批准。
- 变更记录写入 `docs/06-项目变更记录.md`，说明原因、影响、替代方案和决定。
- 未经批准，实现方不得以“顺手做了”为由扩大范围。
- 需求变更后，相关 FR、AC、AT 和追踪矩阵必须同步更新。

## 9. 关键异常场景及处理规则

| 编号 | 场景 | 检测/触发 | 处理规则 | 数据影响与用户提示 |
| --- | --- | --- | --- | --- |
| EX-001 | 不支持的文件格式 | 扩展名不是 `.srt`/`.vtt` | 拒绝导入 | 不创建记录；提示支持格式 |
| EX-002 | 编码不是 UTF-8 | 解码失败或检测到非 UTF-8 | 拒绝，不静默转码 | 不创建记录；提示另存为 UTF-8 |
| EX-003 | 文件为空或全部 cue 无效 | 解析后有效 cue 数为 0 | 拒绝导入 | 不创建记录；报告无效原因 |
| EX-004 | 部分 cue 无效 | 有效数 > 0 且无效数 > 0 | 导入有效 cue，跳过无效 | 创建记录；显示“有效 N，跳过 M”及原因 |
| EX-005 | 文件超过大小/数量限制 | 超过 BR-SUB-07 限制 | 拒绝导入 | 不创建记录；提示拆分或检查文件 |
| EX-006 | 重复导入 | 解析后内容与已有字幕相同 | 默认不导入并提示已存在；MVP 不提供副本导入 | 原记录不变；副本导入为 P1，需另行批准 |
| EX-007 | 磁盘满/写入失败 | 写入异常 | 中止导入，回滚本次写入 | 不产生半份字幕；已有数据不变；提示检查磁盘 |
| EX-008 | 本地数据存储损坏/被占用 | 打开或读写失败 | 显示错误，停止写入，提供恢复/备份说明 | 不静默清空；不覆盖原文件；提示联系用户/恢复备份 |
| EX-009 | 本地词典无该词 | 查询未命中 | 音标显示“暂无音标”；释义显示“本地未收录” | 不自动调用云端；不影响加词和拼写 |
| EX-010 | 无可用英语语音 | TTS 初始化失败或无英语声音 | 显示提示 | 不影响字幕、词条、复习；不回退云端 |
| EX-011 | 未配置 API Key | 云端功能被请求 | 禁用发送，显示配置说明 | 不发起请求；本地功能可用 |
| EX-012 | 网络离线 | 云端请求失败 | 显示离线提示 | 不保存结果；本地功能可用 |
| EX-013 | 云端超时 | 等待超过设定时间 | 显示超时，允许取消/手动重试 | 不保存；不自动循环重试 |
| EX-014 | 限流/配额不足 | 服务返回限流/配额错误 | 显示对应提示 | 不自动重试；用户决定是否稍后重试 |
| EX-015 | 内容被模型拒绝 | 服务返回拒绝/安全提示 | 显示拒绝信息，不绕过 | 不保存；不反复重试同一内容 |
| EX-016 | AI 响应格式异常 | 无法解析/空响应 | 显示“响应无法解析” | 不保存为成功回答；可重试 |
| EX-017 | 用户取消云端请求 | 用户点击取消 | 中止请求，丢弃未确认结果 | 不保存；不产生学习条目 |
| EX-018 | 重复加入同一词条 | 去重键已存在 | 合并语境，不新增词条 | 学习库数量不变；提示已存在 |
| EX-019 | 重复保存 AI 内容 | 同类型同规范化文本已存在 | 提示合并/取消，默认不重复 | 不产生重复条目 |
| EX-020 | 复习中刷新/关闭 | 页面刷新或应用退出 | 已确认作答已保存；未完成队列保留 | 不重复计分；下次继续 |
| EX-021 | 系统日期/时区变化 | 日期回拨/前进 | 使用当前本地日期；不产生负数间隔；不重复每日记录 | 记录按实际本地日期；异常情况记录日志；规则待 OI-17 |
| EX-022 | 删除/归档有词条关联的字幕 | 用户尝试硬删除 | 默认阻止并说明关联数量；只能归档，或明确确认保留冻结快照后删除 | 不静默删除词条和历史；归档可恢复 |
| EX-023 | 字幕文本包含指令性内容 | AI 输出出现异常指令 | AI 输出仅展示，不执行任何操作 | 不自动加词/改状态/删数据；用户确认才保存 |
| EX-024 | 词汇列表过大 | 数千词形 | 分页/虚拟列表，界面可操作 | 不丢失数据；操作有反馈 |
| EX-025 | 词形只有数字/标点/非英文 | 不符合 BR-SUB-08 | 不进入候选列表 | 显示文本仍保留；统计不计入 |
| EX-026 | 同一词不同大小写 | 去重键相同 | 视为同一词条 | 不产生重复；显示首次形式 |
| EX-027 | 时间轴重叠 | 解析发现重叠 | 保留并按文件顺序显示 | 不自动合并；统计按实际出现 |
| EX-028 | 用户归档词条（P1） | 用户点击归档 | 移出复习队列，历史保留 | 可恢复；统计显示已归档 |
| EX-029 | 千问未返回 usage | 响应缺少输入/输出用量 | 使用字符数估算费用并标注“估算” | 不冒充精确账单；记录价格版本 |
| EX-030 | 配置的经济型模型不可用 | 服务返回模型不存在/下线 | 停止请求，提示用户更换模型或稍后重试 | 不静默切换更贵模型；不产生回答 |
| EX-031 | 复习/保存时本地写入失败 | 写入异常或磁盘满 | 停止操作并显示错误；本次未确认内容不标记为已保存 | 不产生半条记录；不重复计分；提示检查磁盘/重试 |
| EX-032 | 硬删除有词条/历史关联的字幕 | 用户确认删除且存在关联 | 要求选择归档或“删除并保留冻结语境快照” | 快照保留原 cue 文本和字幕标题；历史仍可打开 |
| EX-033 | 本地词典许可或覆盖率不足 | 实现/验收时发现词典不可分发或覆盖不够 | 停止宣称 IPA 已验收；记录实际覆盖率和替代方案 | 不自动改为云端 IPA；由用户决定调整范围或词典 |

## 10. 数据使用与千问 API 云端发送边界

### 10.1 基本原则

1. **本地优先**：字幕、词条、复习记录、每日记录、AI 会话、模型配置、费用记录和设置默认保存在本地。
2. **用户主动**：只有用户明确点击发送后才调用千问 API；不存在自动、后台、定时或导入时调用。
3. **最小化**：只发送完成当前请求所必需的内容；不发送整部字幕、完整学习库或无关历史。
4. **默认不带历史**：AI 聊天默认只发送当前用户消息和用户明确添加的附件；会话历史需用户显式开启“最近 N 条”才发送。
5. **可见可控**：发送前显示完整发送内容、附件、历史消息数和目的地；用户可移除附件、取消。
6. **可关闭**：用户可在设置中关闭云端功能；关闭后不产生任何千问请求。
7. **可审计**：本地记录云端结果来源、时间、模型和费用估算；日志不记录敏感内容。

### 10.2 数据分类

| 数据类别 | 默认位置 | 是否可能发送到千问 | 触发条件 |
| --- | --- | --- | --- |
| 原始字幕文件 | 用户本地；应用默认不复制 | 否（不得整文件发送） | 无 |
| 解析后的 cue 文本/时间轴 | 本地 | 仅当前选中的 cue 或用户明确附加的 cue | 用户请求翻译/解释/AI |
| 词条、释义、IPA、语境 | 本地 | 仅当前目标词/短语及用户选择的语境 | 用户请求释义/解释/AI |
| 复习记录、每日记录、学习统计 | 本地 | 否 | 无 |
| AI 会话历史 | 本地 | 默认不发送；用户显式开启后仅发送最近 N 条 | 用户开启开关、预览并确认 |
| 模型配置与费用记录 | 本地 | 否（模型标识用于组装请求，费用记录本身不上传） | 无 |
| API Key | 本地安全配置 | 仅作为千问请求认证头；不得进入提示词、URL 参数、预览或日志 | 用户确认执行云端请求 |
| 日志 | 本地 | 否 | 无 |
| 备份/导出文件（若实现） | 本地 | 否 | 用户手动导出；不自动上传 |

### 10.3 云端发送矩阵

| 用户动作 | 发送到千问的内容 | 明确不发送 | 触发方式 | 预览要求 |
| --- | --- | --- | --- | --- |
| 单句翻译 | 当前 cue 的清洗后文本 | 其他 cue、整部字幕、学习记录、密钥 | 用户点击“翻译”并确认 | 显示该句全文和“千问 API” |
| 单词释义（云端） | 目标单词；若用户选择结合语境，附加当前 cue | 整部字幕、其他词条、历史 | 用户点击“查释义”并确认 | 显示单词和可选语境 |
| 语境解释 | 目标单词/短语 + 当前 cue | 相邻 cue（除非用户主动添加）、整部字幕 | 用户点击“解释”并确认 | 显示词、cue、目的地 |
| AI 语法解释 | 用户消息 + 可选当前 cue/词 | 学习历史、其他字幕、整部字幕 | 用户点击发送 | 显示消息、附件、历史消息数（默认 0） |
| AI 重新造句 | 用户消息 + 目标词/句 | 整部字幕、复习记录 | 用户点击发送 | 同上 |
| AI 短文生成 | 用户主题/词表 + 可选当前 cue | 整部字幕、私人笔记（除非用户粘贴） | 用户点击发送 | 同上 |
| AI 纠错 | 用户输入的英文 + 可选目标词/句 | 学习历史、其他字幕 | 用户点击发送 | 同上 |
| AI 自由问答（P0） | 用户消息 + 用户选择的附件 | 未选择的内容、未开启的历史 | 用户点击发送 | 同上；开启历史时显示具体条数 |
| 单词/短语比较（P1） | 两个词/短语 + 可选语境 | 整部字幕 | 用户点击发送 | 同上 |

### 10.4 同意与预览流程

1. **首次使用**：显示数据边界说明，至少包括：
   - 哪些数据会发送到千问 API；
   - 不会把整部字幕、完整学习库或密钥作为内容发送；密钥只用于请求认证；
   - 千问可能按其服务条款处理/保留数据，应用无法保证云端删除；
   - 用户可关闭云端功能。
2. **同意**：用户明确接受后才可发送；拒绝则云端功能不可用，本地功能可用。
3. **每次发送**：显示“本次将发送”面板，包含完整文本、附件、会话历史消息数（默认 0）和目的地。
4. **历史开关**：用户显式开启“携带最近 N 条消息”后，预览列出这 N 条消息的完整内容；实际只发送这些内容。
5. **确认**：用户点击发送才产生请求；取消不产生请求。
6. **变更**：用户修改消息、附件或历史开关后，预览更新；实际发送必须与最终预览一致。
7. **关闭**：设置中可关闭云端；关闭后入口显示不可用，不产生请求。

### 10.5 不得发送的数据

无论用户是否同意，以下内容不得发送到千问：

- 完整字幕文件或整部字幕的全部 cue；
- 完整学习库、复习历史、每日记录；
- API Key、密钥、环境变量内容（API Key 仅可作为千问认证头，不得作为提示词、URL 参数、预览或日志内容发送）；
- 本地文件路径、本地数据存储内容、日志全文；
- 与当前请求无关的其他字幕或私人笔记；
- 用户未在预览中看到的内容。

### 10.6 API Key 与日志

- API Key 由用户在本地配置；具体方式由架构阶段决定，但不得写入 Git 仓库。
- 界面只显示掩码；复制/查看完整 Key 不属于 MVP 功能。
- 日志、错误消息、发送预览和提示词中不得出现完整 Key。
- 仓库检查应能通过简单的密钥扫描；发现泄露时必须立即更换 Key，并记录事件（不记录 Key 本身）。

### 10.7 缓存、保留与删除

- 翻译/解释结果和 AI 会话历史本地保存，直到用户清除或删除。
- 缓存命中时不重复发送云端请求；用户可手动刷新。
- 删除 AI 会话不删除已保存的学习条目。
- 删除缓存不影响词条、复习记录和每日记录。
- 云端供应商侧的数据保留/删除由供应商政策决定；应用只能控制本地数据，不能承诺云端删除。该限制必须在首次同意说明中告知用户。
- 本地数据删除/导出能力若纳入 MVP，需另行确认（OI-11、OI-12）。

### 10.8 供应商与成本限制

- 千问 API 的具体模型由用户配置；默认经济型模型；模型不可用时不得静默升级（FR-091）。
- 应用不得硬编码用户 Key 或代替用户购买服务。
- 应用不得在后台批量调用、自动重试或生成大量内容以增加费用。
- 用户应能知道当前是否启用云端；关闭后不得产生费用。
- 每次用户主动调用应产生本地费用记录或估算，并标注价格版本和“估算”性质（FR-092）。

### 10.9 隐私验收条件

- AC-DATA-01：启动、导入、浏览、复习、打开聊天窗口但不发送时，网络监控无千问请求。
- AC-DATA-02：单句翻译请求的发送内容只包含该 cue，不包含其他 cue。
- AC-DATA-03：AI 聊天发送内容与预览完全一致；移除的附件不出现。
- AC-DATA-04：仓库、日志、界面、预览中找不到完整 API Key。
- AC-DATA-05：关闭云端后，所有云端入口不可用且无请求。
- AC-DATA-06：删除 AI 会话后，已保存学习条目仍存在。
- AC-DATA-07：未开启“携带最近 N 条消息”时，AI 请求只含当前消息和明确附件，不含任何先前消息。
- AC-DATA-08：费用记录只保存在本地，不随 AI 请求发送；记录内容与本次调用一致。

## 11. 验收标准与需求追踪

### 11.1 验收原则

- **可观察**：验收结果必须能从界面、数据、日志或测试报告中看到。
- **可复现**：使用固定字幕样本、固定操作步骤和可控日期。
- **可判定**：通过/失败明确，不使用“基本可用”“体验良好”等模糊表述。
- **真实性**：测试失败就记录失败；未覆盖就写未覆盖；不得伪造。
- **分层**：功能验收、工程验收、认知验收、英语学习成效验收分开进行。

### 11.2 端到端验收场景

#### AT-001 SRT 导入与统计

- **给定**：一份含 3 条有效 cue 的标准 SRT，词形已知。
- **当**：用户导入并打开字幕。
- **则**：字幕库新增 1 条；cue 数、时间轴、文本正确；词次和去重词汇量与预期一致；未产生云端请求。

#### AT-002 VTT 导入

- **给定**：含 `WEBVTT`、`NOTE`、`STYLE` 和 2 条有效 cue 的 VTT。
- **当**：用户导入。
- **则**：只显示 2 条台词；`NOTE`/`STYLE` 不显示、不统计；时间轴正确。

#### AT-003 无效与部分无效导入

- **给定**：文件 A 含 2 条有效、1 条无效 cue；文件 B 全部无效。
- **当**：分别导入。
- **则**：A 导入 2 条并报告跳过 1 条；B 被拒绝且不创建记录；已有数据不变。

#### AT-004 重复导入

- **给定**：已导入字幕 X。
- **当**：再次导入内容相同的 X。
- **则**：提示已存在且不新增；取消后数量不变；MVP 界面没有“作为新副本导入”入口；字幕总数不变。

#### AT-005 浏览、按需翻译与缓存

- **给定**：已导入字幕，网络可用，云端已同意。
- **当**：选中一条 cue 请求翻译，查看预览并确认；随后再次请求同一 cue。
- **则**：预览只含该 cue；确认后显示中文和来源；第二次显示本地缓存且无云端请求；其他 cue 未发送。

#### AT-006 离线核心能力

- **给定**：断开网络。
- **当**：导入字幕、浏览、加词、查询本地词典中存在的词的 IPA、播放 TTS、完成复习、重启。
- **则**：上述操作成功；云端翻译/AI 显示不可用；无无限加载；数据不丢失。

#### AT-007 词汇、音标、朗读与详情

- **给定**：字幕中有一个词典可查的词。
- **当**：加入学习库、打开详情、播放单词和句子、从另一 cue 再加入同一词。
- **则**：词条状态为待学习；显示 IPA、释义、语境；播放成功；同一词条有 2 条语境；无重复词条。

#### AT-008 拼写、词义回忆与即时保存

- **给定**：学习库有 3 个有释义的词。
- **当**：完成拼写和词义回忆各若干题，刷新页面，重启应用。
- **则**：每次尝试有记录；错误显示正确答案；下次日期按规则更新；刷新/重启后记录不丢、不重复；未完成队列保留。

#### AT-009 跨日期掌握与回退

- **给定**：可控日期测试环境。
- **当**：同一天答对 3 次；再模拟 3 个不同日期成功且至少一次距首次成功 ≥7 天，最近一次成功；随后一次“忘记”。
- **则**：同日 3 次不掌握；满足条件后变为已掌握；忘记后回到学习中，下次日期为 1 天后。

#### AT-010 AI 发送预览、保存与隐私

- **给定**：已同意云端，打开 AI 聊天并选择当前 cue/词。
- **当**：输入消息但不发送；查看预览、移除附件、发送；选择回答片段保存；取消另一次保存。
- **则**：未发送时无请求；发送内容与预览一致；移除的附件未发送；回答有 AI 标识；确认后条目出现；取消后无条目；保存不改变词条状态。

#### AT-011 AI 异常

- **给定**：分别模拟无 Key、离线、超时、限流、内容拒绝、格式异常。
- **当**：发送请求。
- **则**：显示可区分的错误；不自动循环重试；不保存成功假象；本地功能可用。

#### AT-012 每日记录与统计

- **给定**：新的一天，学习库有若干词。
- **当**：仅打开应用；仅导入字幕；完成复习；加入词条；保存 AI 内容。
- **则**：打开/导入不产生学习日；复习/加词/保存产生对应计数；统计与记录一致；跨日期分列。

#### AT-013 重启与继续学习

- **给定**：用户正在浏览某字幕第 N 条 cue，复习队列未完成。
- **当**：关闭并重启应用。
- **则**：首页显示“继续学习”；点击回到该字幕/cue 和剩余队列；不自动调用云端。

#### AT-014 本地访问限制

- **给定**：应用运行中。
- **当**：从本机访问、从局域网另一设备访问、从其他网页发起跨站请求。
- **则**：本机可访问；另一设备失败；非本应用页面的跨站请求被拒绝；无需登录；无多用户入口。

#### AT-015 密钥与日志保护

- **给定**：已配置 API Key。
- **当**：检查仓库、日志、界面、发送预览、错误消息。
- **则**：均不出现完整 Key；界面为掩码；仓库扫描无硬编码 Key。

#### AT-016 AI 内容重复保存

- **给定**：已保存一个 AI 单词条目。
- **当**：再次保存同类型同规范化文本。
- **则**：提示合并/取消，默认不产生重复条目。

#### AT-017 P1 表达练习/会话总结（仅在纳入 MVP 时）

- **给定**：P1 功能已批准。
- **当**：完成一次表达练习和一次复习会话。
- **则**：表达尝试被记录但不单独计入掌握；会话总结数字与历史一致。

#### AT-018 P1 归档（仅在纳入 MVP 时）

- **给定**：P1 归档功能已批准。
- **当**：归档一个词条，再恢复。
- **则**：归档后不进入队列、历史保留；恢复后按历史重算，不伪造掌握。

#### AT-019 语境解释（P0）

- **给定**：已导入字幕、云端已同意且网络可用。
- **当**：从 cue 请求语境解释，查看预览并确认；随后保存为笔记；另一次取消。
- **则**：预览只含目标词/短语和当前 cue；结果标注“语境解释（AI 辅助）”和来源；保存需确认；取消不产生条目；成功结果进入本地缓存。

#### AT-020 性能基线（验收目标）

- **给定**：2,000 条 cue 的测试字幕、参考 Mac。
- **当**：导入、启动、查询、朗读、保存作答。
- **则**：达到 NFR-001 的验收目标，或记录实际结果并说明差异；不得伪造成达标。

#### AT-021 备份/恢复（仅在纳入 MVP 时）

- **给定**：P1 备份功能已批准。
- **当**：导出本地数据，清空/换机后恢复。
- **则**：字幕、词条、历史、状态恢复；导出文件提示含个人数据；无云端上传。

#### AT-022 字幕归档与受控删除（P0）

- **给定**：字幕 A 无关联记录，字幕 B 有词条和复习历史。
- **当**：归档 A 并恢复；尝试硬删除 B；选择保留冻结快照后删除 B。
- **则**：归档/恢复不影响 cue 和统计；B 的硬删除默认被阻止并说明关联；保留快照后 B 消失，但词条详情仍显示原 cue 文本、字幕标题和“来源已删除”，复习历史仍可打开；任何路径都没有静默删除学习记录。

#### AT-023 AI 上下文默认值与费用记录（P0）

- **给定**：已有包含历史消息的会话，云端已同意。
- **当**：不开启历史开关发送一次；再开启“最近 2 条”发送一次；检查费用记录。
- **则**：第一次只发送当前消息和明确附件；第二次只发送预览列出的最近 2 条；两次记录均包含时间、用途、实际模型、用量或“按字符估算”、费用和币种；记录只在本地，不随请求发送。

### 11.4 覆盖检查

- 所有 P0 FR 均有至少 1 个 AC 和 1 个 AT/检查方式。

- 第 7 节的关键 NFR 有验证方式；性能、兼容性和规模指标标注为“验收目标/待验证”，未验证前不得宣称满足。
- 掌握规则、统计口径、复习间隔和文件大小限制已随 V0.2 批准；其中文件阈值和词典许可/覆盖率仍需真实样本或实现前验证，验证结果记录后再调整。

### 11.5 认知验收

每个阶段结束时，用户应能用自己的话解释：

1. 该阶段模块的职责和文件位置；
2. 关键数据从哪里来、到哪里去；
3. 哪些数据在本地，哪些可能发送到云端；
4. 如何用一条命令或一组操作验证功能；
5. 当前已知限制和未解决问题。

认知验收不等于功能验收；不能因为“能跑”就跳过理解，也不能因为“理解了”就掩盖测试失败。
