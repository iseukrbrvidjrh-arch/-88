## 一、项目背景与目标

SceneLingo 以英文影视字幕为学习材料，帮助用户从真实语境中积累词汇、理解句子，并通过主动回忆与间隔复习巩固所学。同时，项目作为软件工程实践载体，按需求、设计、实现、测试和验收的流程推进。

项目先服务个人使用，验证实际英语学习效果，再依据使用和评估结果考虑后续优化及商业化。本阶段不开发商业化功能，也不以功能数量代替学习成效。

## 二、产品范围与核心功能

### 2.1 字幕导入与处理

1. 导入英文 SRT、VTT 字幕。
2. 自动解析字幕内容，提取词汇，并进行去重与统计。
3. 保留字幕语境，供后续理解和学习使用。

### 2.2 语言理解与朗读

1. 提供中英文翻译、单词释义和 IPA 音标。
2. 提供英文单词和句子的朗读。

### 2.3 练习与学习记录

1. 支持拼写测试、主动回忆和间隔复习。
2. 保存学习进度、复习历史和词汇掌握状态。
3. 词汇掌握状态应反映跨日期的复习表现，不能简单等同于当天答对三次；具体判定规则由后续需求与设计明确。

### 2.4 AI 英语学习辅助

1. 集成千问 API 的 AI 聊天窗口。
2. 支持语法解释、重新造句、短文生成和英语纠错。
3. AI 生成内容经用户确认后，方可保存到个人学习库。

### 2.5 数据边界

字幕及个人学习数据默认保存在本地。调用千问 API 时的数据传输范围、触发方式和提示方式须在后续需求与设计中明确；未经授权不得上传字幕或私人文件。

## 三、技术路线

采用面向 macOS 个人使用的本地应用方案。以下为已确认的技术选型；模块划分、数据模型和 API 契约由后续设计文档确定。

| 领域 | 选型 |
| --- | --- |
| 前端 | HTML / CSS / JavaScript |
| 后端 | Python / FastAPI |
| 数据库 | SQLite |
| AI 服务 | 千问 API |

| 测试 | pytest |

本地服务仅监听 `127.0.0.1`。API Key 不得写进代码仓库。

1. 当前不开发商业化功能，不擅自增加项目范围。
2. 未经授权，不上传字幕或私人文件；个人学习数据默认保存在本地。
3. API Key 不得写入代码仓库。
4. 本地服务仅监听 `127.0.0.1`。
5. 英语学习效果必须独立验证，不能仅以软件功能完成度代替。

7. 词汇掌握不能简单等同于当天答对三次。

9. 文档保持清晰、结构完整、可长期维护；发生范围或设计变更时记录原因与决定。

## 八、验收原则

- **产品验收：** 在后续批准的验收标准下，验证字幕导入、学习、AI 辅助、复习及进度保存的完整使用流程。
- **工程验收：** 依据任务卡和测试计划检查功能、持久化及 macOS 本地运行结果，记录实际测试结果和限制。
- **认知验收：** 用户能够解释已实现模块的职责、关键数据流及基本验证方法。
- **学习成效验收：** 建立独立的英语能力基线，持续记录个人使用情况，并通过后续独立测评判断学习效果；具体方法在需求与验收文档中确定。
