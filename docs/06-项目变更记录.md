## 2026-10-30 — 字幕无效 cue 数量持久化

| 项目 | 内容 |
| --- | --- |
| 变更 | 经用户批准，为 `subtitle` 增加可空的 `invalid_cue_count`，由新增 V3 迁移实施，不修改 V1/V2 历史迁移 |
| 原因 | TASK-003 导入响应可报告跳过数量，但旧模型无法在重启后满足 TASK-004 字幕库的异常标识要求 |
| 兼容语义 | V3 前已有字幕保留 `NULL`（未知）；V3 后新导入写入准确的非负整数，明确的 0 与未知严格区分 |
| 影响 | 只影响字幕导入摘要和只读浏览；无效 cue 仍被跳过，不保存其文本，不增加原因摘要，不涉及归档、学习库或后续业务 |
| 批准人 | 用户（项目负责人） |
