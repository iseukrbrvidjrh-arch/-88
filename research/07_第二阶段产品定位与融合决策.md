# 第二阶段：产品定位与融合决策

> **范围声明**：本文是文档设计，不修改源码、数据库、配置、测试、打包文件或用户数据；现有未提交改动保持不变。第一阶段结论主要来自静态证据，未将 A 的 README 声称视为运行验证。本阶段不复制 enjoy_player 的代码、Flutter widget、Drift schema、资源或迁移；任何直接复用需另行许可证审查。

## 推荐定位

**SceneLingo 2.0 = 字幕优先、媒体辅助、本地优先的真实语境英语学习工具。**

核心不是做通用播放器，而是让用户围绕一个 cue 完成：理解 → 查词/听读 → 保存语境 → 主动回忆 → 跨日期复习。媒体播放和时间轴是增强上下文的可选能力，不应取代现有字幕学习核心。

证据：SceneLingo 当前入口和实体见 `app/api/subtitles.py`、`app/services/subtitle_import.py`、`app/repositories/migrations/versions.py`；A 的时间轴/训练思想见第一阶段 `01_参考项目完整功能分析.md`。

## 目标用户与非目标

目标用户是希望用个人影视字幕长期学习、重视本地隐私、接受少量 AI 辅助、需要可追踪复习的人。首要场景是个人 macOS 单机学习，不是社交、内容平台或商业课程系统。

非目标：立即重写 Flutter；同时实现所有 Listen/Echo/Dictation；立即支持 YouTube、账号、同步、多平台；自动整部字幕 AI 加工；云端替代本地核心能力。

## 融合决策门

| 决策 | 推荐默认值 | 未决前不做 |
|---|---|---|
| 是否播放媒体 | 先支持“可选音频/视频上下文”，不改变字幕核心 | 不新增播放器或媒体表 |
| 第一训练实验 | 听写与跟读二选一，默认优先听写 | 不同时实现两套录音/评分链 |
| AI/评分出网 | 核心闭环离线；AI 必须用户确认；评分另行决定 | 不新增后台上传 |
| 同步/账号 | 暂不做 | 不设计 sync queue |
| 许可证 | 独立重实现，只借鉴思想 | 不复制 A 代码/资产/schema |

## 成功标准

不是功能数量，而是：用户能在短时间完成 cue 学习动作；主动回忆率提高；跨日期复习持续；一个词条保留有用语境；离线核心不中断；AI 调用能转化为保存或复习内容。
