# 技术融合可行性与风险评估

## 1. 总体结论

两项目产品理念部分兼容，但技术栈不适合直接拼接：enjoy_player 是 Dart/Flutter/Drift/Riverpod/多媒体原生插件体系；SceneLingo 是 Python/FastAPI/原生 JS/SQLite/手写 SQL。建议渐进式升级，而不是整体迁移或重构。融合对象应是经过验证的产品思想和领域能力，不是源代码和表结构。

## 2. 复用分类

| 内容 | 处理方式 | 原因 |
|---|---|---|
| A 的 UI/业务源代码、Flutter widget、数据库迁移 | 不直接复用；独立重实现 | AGPL-3.0 触发许可证合规义务；技术栈不同，迁移成本高 |
| “媒体时间轴作为学习上下文” | 借鉴设计思想 | 思想/产品流程与代码不同；适合映射到 B 的 cue/context_ref |
| Listen/Echo/Dictation 的训练概念 | 借鉴并做小实验 | 先验证学习效果和用户需求，避免把声称当作事实 |
| A 的 Drift schema | 不迁移 | B 的学习事实模型和数据边界不同，直接迁移会引入大量实体 |
| A 的多平台播放插件 | 暂不引入 | B 目标是 macOS；Flutter 与当前 Web/Python 部署路径不兼容 |
| 多供应商 AI | 独立抽象 provider port | B 已有 Qwen 网关；新增供应商应保持预览、费用和隐私边界 |
| 训练算法/SRS 思想 | 比较算法后独立实现 | 必须以可测学习效果和 B 的不可变历史为准 |

## 3. 数据库影响

若未来加入视频/音频同步，B 不应直接照搬 A 的完整 schema。优先考虑以现有 `subtitle`/`cue` 为事实，新增最小的媒体元数据和 cue 时间定位关联；是否落库、如何处理文件移动、媒体指纹、多个字幕轨道和删除语义，需要单独需求批准。跟读/听写/录音会涉及 recording、练习会话、评分事件、隐私保留策略，也不能通过“顺手加几列”解决。

现有 B 的 `review_attempt` 是不可变事实，`review_state` 是可重建投影；任何新训练模式应追加明确的 mode/事件模型或经过评审的扩展，不修改历史语义。AI 供应商扩展还会影响 `model_id`、usage、价格版本、缓存键和 request_id 幂等。

## 4. 主要风险

1. **许可证风险**：AGPL-3.0 代码直接进入不同分发模式的 SceneLingo 可能产生源代码提供义务；仅引用公开 API/思想与复制代码不同。
2. **定位风险**：从字幕学习工具扩展为全媒体训练平台会增加播放器、文件管理、同步、录音和设备权限，可能挤压英语学习主目标。
3. **数据迁移风险**：现有用户词条、语境、复习历史和 AI 记录不可因新模型丢失；任何迁移要有备份、回滚和旧数据重放测试。
4. **状态复杂度**：原生 JS 单页与多训练模式叠加会造成流程状态冲突；Flutter 重写虽能改善组件体系，却会引入全栈迁移成本，不应预设为答案。
5. **性能风险**：媒体播放、字幕分页、大文件、录音和 AI 流式可能同时竞争本地进程；需要真实数据基线。
6. **平台风险**：A 的跨平台依赖不能说明 macOS 后端集成可直接使用；B 的 TTS/Keychain/打包也有自己的平台约束。
7. **学习效果风险**：跟读评分、AI 纠错和多模式数量可能看似先进，但没有用户实验就不能证明有效。

## 5. 推荐的渐进式路线（仅评估，不执行）

- **优先级 0：可靠性基线**：确认当前字幕—词汇—复习—记录闭环、迁移、备份和测试结果，建立真实数据口径。
- **优先级 1：上下文体验**：在不改变核心事实模型的前提下，改善 cue、词条、多个语境、音频/播放定位的衔接。
- **优先级 2：一个训练模式实验**：在听写或跟读中选择一个最小闭环，定义学习指标和离线降级，不同时引入全部 A 功能。
- **优先级 3：AI/provider 抽象**：保持 Qwen 现有功能稳定，再评估多供应商和本地模型；统一费用、缓存和隐私契约。
- **优先级 4：导出/备份与可维护性**：在扩大功能前完善用户数据可携带性、前端模块边界和升级演练。

以上是决策建议，不是立即执行的重构清单。

## 6. 需要产品负责人确认的前置问题

- SceneLingo 2.0 的核心对象是“字幕学习”还是“媒体训练平台”？
- 是否必须支持视频/音频播放，还是先支持外部播放器/音频文件定位？
- 是否接受任何云端发音评分，还是坚持全部核心能力离线？
- 是否需要多设备同步/账号；若不需要，是否永久保持单机？
- A 的 AGPL 许可证是否允许目标发布方式承担对应义务？
- 第一批实验选择听写、跟读、表达还是只优化现有复习？
