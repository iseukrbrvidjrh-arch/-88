## 1. 功能目标

建立**唯一**的云端出口，并完成首批云端功能：

- Key 存 macOS Keychain；界面只显示掩码与“已配置/未配置”。
- 首次使用前显示数据边界并取得同意；可随时关闭云端。
- 两阶段发送：先生成**不可变发送计划**与预览，用户确认后才执行。
- 单句翻译、单词释义（千问补全）、语境解释三类调用。
- 结果按规则缓存并标注来源；每次调用记录费用。
- 失败分类可读；不自动重试、不静默换模型。

## 4. 输入与输出

**输入**

- Key 设置：Key 明文（仅此一次，写入 Keychain）。
- 发送计划请求：任务类型（翻译/释义/语境解释）、目标文本、语境（当前 cue）、可选历史消息（默认无）。
- 执行请求：计划 ID + 一次性令牌。
- 设置：云端开关、模型选择。

**输出**

- 发送计划：预览内容（用户消息、附件文本、历史条数、目的地）、计划 ID、过期时间；**不可修改**，改动需重新生成。
- 执行结果：流式文本或完整文本、来源标签（千问 API）、模型标识、用量与估算费用；失败时为分类错误。
- Key 状态：`configured` / `not_configured`，绝不返回明文。
- 费用记录：时间、用途、模型、用量、估算费用、币种、价目版本、状态。

## 5. 技术约束

1. Key 只存 Keychain（`keyring`），不写数据库、不写日志、不写预览、不写 URL、不写提示词；错误信息脱敏。
2. 读取 Key 只在发请求瞬间发生；前端永远拿不到明文。
3. 发送计划必须绑定：内容哈希、有效期（如 5 分钟）、一次性令牌；执行时校验内容未被改动、未过期、未重复使用。
4. 预览内容 = 实际发送内容；不得在服务端追加字幕、历史或学习数据。
5. 默认模型为经济型；模型不可用返回明确错误，**不静默升级**；每次调用记录实际模型。
6. 只有用户主动触发才请求；无同意、无 Key、云端关闭时一律拒绝执行，且不产生请求。
7. 超时/限流/离线/内容拒绝/响应格式异常分类映射；不自动循环重试。
8. 缓存键 = 类型 + 规范化源文本 + 语境哈希 + 目标语言；命中不发请求并标“本地缓存”；失败不缓存。
9. 费用记录以 `request_id` 唯一；拿不到 usage 时按字符估算并标注，不冒充账单。
10. HTTP 客户端设置显式超时与最大响应大小；流式取消必须真正中断连接。
11. 网关是唯一出口：其他模块不得直接 import httpx 或发网络请求。

## 6. 实现边界

**做**

- Key 生命周期、云端同意与开关、模型配置、发送计划与预览、三类调用、缓存、来源标签、费用记录与查询、错误分类。

**不做**

- 不做 AI 聊天会话、任务模板、历史携带 UI、内容保存（TASK-011）。
- 不做批量翻译、导入时自动翻译。
- 不做费用硬上限、自动停机（SRS 明确未批准）。
- 不做多供应商切换。

## 7. 自动化测试要求

使用**假网关**，不访问真实网络：

1. 无 Key：计划/执行被拒，返回配置指引，零请求。
2. 云端关闭：同样零请求。
3. 未同意：首次调用前被拦截；同意后可执行。
4. 预览即发送：执行时的请求体与预览快照一致（逐字段断言）。
5. 计划篡改：修改计划内容后执行被拒；重复执行被拒；过期执行被拒。
6. 默认经济模型：配置缺省时为经济型；模型不可用错误不触发其他模型调用。
7. 缓存：同请求第二次命中缓存、零请求、来源标“本地缓存”；不同语境不串味。
8. 费用：成功调用一条记录；重试为新请求新记录；`request_id` 重复被拒；无 usage 时标“按字符估算”。
9. 错误映射：超时、限流、离线、拒绝、格式异常分别映射到不同错误码，且不自动重试。
10. 脱敏：构造失败响应与日志，断言不含 Key 与完整提示词。
11. 网关唯一性：静态检查或测试断言其他模块未直接发起 HTTP。

## 8. 人工验收标准

1. 未配置 Key 时，翻译/AI 入口显示配置指引，点击不发送。
2. 保存 Key 后，界面只显示掩码；重启后仍为“已配置”。
3. 首次翻译前出现数据边界说明；拒绝后不发送。
4. 预览面板显示将发送的文本与目的地；取消后无请求。
5. 成功翻译后，结果标注“千问 API”与模型；再次请求显示“本地缓存”。
6. 关闭云端后，入口不可用，已有缓存仍可查看。
7. 费用页显示本次调用记录；断开网络时显示网络错误，可手动重试。
8. 检查日志与数据库：无完整 Key、无完整提示词。
