# TASK-012 学习记录、统计与继续学习

| 项目 | 内容 |
| --- | --- |
| 任务编号 | TASK-012 |
| 状态 | 待开始 |

| 验收 | 用户（按 §8 人工验收） |

## 1. 功能目标

让用户看到真实、可核对的学习进度，并能一键回到上次位置：

- 每日记录：日期、复习次数、正确次数、新增词条数、AI 内容保存数（表达练习 P1 不实现）。
- 状态统计：词条总数、待学习/学习中/已掌握、今日到期数。
- 继续学习：恢复最近字幕与 cue、未完成复习队列位置。
- 所有数字由原始记录计算，不做手工值、不缓存假总数。

## 2. 相关需求编号

- FR-080 每日学习记录、FR-081 词汇状态统计、FR-082 学习进度与继续学习
- BR-REC-01 ~ BR-REC-07、BR-REV-01（到期口径）
- AC-FR-080 ~ AC-FR-082、AT-012（每日记录与统计）、AT-013（重启与继续学习）

## 3. 涉及模块

- `app/services/progress.py`：每日聚合、状态统计、续学
- `app/repositories/`：聚合查询
- `app/api/`：每日记录、统计、继续学习、保存进度路由
- `app/web/`：首页“继续学习”、记录页、统计卡片

## 4. 输入与输出

**输入**

- 日期范围（默认最近 7 天）或单日（本地日期）。
- 统计请求（无参数，返回当前状态）。
- 进度保存：最近字幕 ID、cue ID、复习队列位置、最近活动时间（由系统在对应操作后写入，不由用户填）。

**输出**

- 每日记录：日期、复习次数、正确次数、正确率、新增词条数、AI 保存数。
- 统计：未归档词条总数、三种状态数量、今日到期数、关联字幕数（可选）。
- 继续学习：目标字幕与 cue、未完成队列剩余数；数据失效时返回“无法恢复”，前端回到字幕库。
- 空数据：显示“暂无记录”，不显示 0 冒充真实数据以外的含义（若为 0 则如实显示 0）。

## 5. 技术约束

1. 所有计数从 `review_attempt`、`learning_item`、`ai_message`/保存记录实时聚合；不新建手工维护的每日计数表。
2. 日期口径为**本地日历日**，由注入时钟提供；跨时区以当前本地日期为准。
3. 正确次数定义：拼写正确且最终评分 `good`，或词义回忆 `good`；“模糊/忘记”不计为正确（BR-REC-03）。
4. 同一次 AI 单词保存可同时计入“新增词条数”和“AI 保存数”，但同一指标内不重复。
5. 仅打开应用、导入、浏览、播放不产生记录（BR-REC-01）。
6. 统计必须与明细一致；提供内部重算能力与不一致告警日志（不静默改数）。
7. 继续学习引用失效（字幕/ cue 已删除）时降级，不报错、不崩溃。
8. 获取进度不得触发任何云端请求（BR-REC-05）。

## 6. 实现边界

**做**

- 每日记录、统计、继续学习、进度写入与失效降级、空状态、日期切换。

**不做**

- 不做趋势图、导出、周报、成就系统（P1 未批准）。
- 不做学习时长统计（SRS 明确不做）。
- 不做跨设备同步。
- 不新增物化统计表（除非后续单独批准性能优化）。

## 7. 自动化测试要求

通过注入时钟构造跨日期场景：

1. 当日 3 次复习（2 次 `good`、1 次 `again`）→ 复习 3、正确 2、正确率 2/3。
2. 仅导入字幕、仅打开应用 → 不产生学习记录。
3. 加 2 个词（其中一个来自 AI 保存）→ 新增词条 2、AI 保存 1。
4. 跨日期：两天活动分列两条记录，不合并。
5. 统计：三状态之和等于未归档词条数；到期数按 BR-REV-01 口径。
6. 删除/归档字幕不影响词条统计；归档词条（P1 未实现时用测试数据构造）不计入三状态。
7. 继续学习：保存后重启可恢复；字幕被删除后返回“无法恢复”且不抛错。
8. 一致性：篡改一条历史后重算，统计随明细变化，并记录告警。
9. 统计接口无云端调用（假网关断言零调用）。

## 8. 人工验收标准

1. 完成几次复习与加词后，记录页数字与实际操作一致。
2. 只打开应用不做任何操作，记录页不新增学习日。
3. 首页显示“继续学习”，点击回到上次字幕与 cue。
4. 删除上次字幕后再打开应用，首页提示无法恢复并进入字幕库。
5. 统计卡片三状态数量与学习库筛选结果一致。
6. 关闭重启后所有数字不变。

## 9. 禁止事项

- 禁止手工维护每日计数或“修正”统计数字。
- 禁止用 UTC 日期显示给用户。
- 禁止把学习库词条数与字幕去重词汇量混用。
- 禁止为首页性能缓存过期统计而不失效。
- 禁止实现未批准的统计功能（趋势、成就、时长）。
- 禁止修改 `docs/`、`tasks/`、`CLAUDE.md`、`AGENTS.md`。
- 禁止未经批准提交或推送。
