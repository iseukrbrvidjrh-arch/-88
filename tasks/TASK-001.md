## 1. 功能目标

交付一个**能在本机启动、能被验证、默认拒绝外部访问**的应用骨架：

- 启动后只监听 `127.0.0.1`，提供静态占位页。
- 提供只读健康检查接口，返回服务状态、版本和时间。
- 建立配置、错误响应、结构化日志的统一入口。
- 建立本地 HTTP 防护：Host 校验、Origin 校验、进程内一次性访问令牌、安全响应头、无 CORS 放行。

本任务完成后，应用**还没有任何学习功能**，但后续所有任务都可以在此骨架上增量实现。

## 2. 相关需求编号

- FR-001 单用户本地运行与访问限制
- NFR-006 安全（本地监听、Key 不入库、文件校验）
- NFR-011 可维护性（分层与目录）
- AT-014 本地 HTTP 安全（本任务先覆盖可测部分，其余在 TASK-013 汇总）

## 3. 涉及模块

- `app/main.py`：组合根、静态资源挂载、启动检查
- `app/core/`：配置、错误码与错误响应、日志、安全（Host/Origin/token）、时钟与版本
- `app/api/`：健康检查与系统信息路由
- `app/web/`：占位首页（原生 HTML/CSS/JS，无构建链）

## 4. 输入与输出

**输入**

- 启动参数/配置：端口（默认值由配置决定）、数据目录（默认 `~/Library/Application Support/SceneLingo`）、日志级别。
- HTTP 请求：`GET /api/v1/health`、`GET /api/v1/system/info`、静态资源请求。

**输出**

- `GET /api/v1/health`（公开、只读）→ `200`，固定字段：`status`、`version`、`time`。不含主机名、路径、配置、依赖状态等敏感信息。
- `GET /api/v1/system/info`（需令牌）→ `200`，返回版本、安全模式（如 `locale_only`）、数据目录**是否可用**（布尔），不返回绝对路径。
- 统一错误响应：`{"error": {"code": "...", "message": "..."}}`，不返回堆栈。
- 结构化日志：写到数据目录 `logs/`，按日滚动；不记录请求体、查询串全量、令牌、Key。
- 数据目录：首次启动创建，权限仅当前用户可读写（`0700`）。

## 5. 技术约束

1. Python + FastAPI + Uvicorn，单 worker；不引入 ORM、模板引擎、前端框架或 Node 构建链。
2. 监听地址固定 `127.0.0.1`；端口可配置，配置非法时启动失败并给出明确错误。
3. **Host 校验**：仅接受 `127.0.0.1[:port]` 与 `localhost[:port]`；其余返回 `403`。
4. **Origin 校验**：对 `POST/PUT/PATCH/DELETE` 要求 `Origin` 存在且与本地源一致；缺失或外站一律拒绝。不得用 `*` 放行。
5. **访问令牌**：进程启动时生成高强度随机令牌，仅注入到本地页面；除 `health` 外所有 `/api/*` 要求请求头令牌，缺失/错误返回 `401`。令牌不写日志、不写磁盘明文、不进 URL。
6. 关闭 CORS 放行；如需中间件，默认拒绝而非默认允许。
7. 关闭 `/docs`、`/redoc`、`/openapi.json`（或统一受令牌保护），避免无认证暴露内部契约。
8. 响应头至少包含：`Content-Security-Policy`（禁止内联脚本或使用 nonce）、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、`Cache-Control: no-store`（API 响应）。
9. API 只接受/返回 `application/json`；静态资源除外。
10. 依赖版本在 `requirements` 类文件中固定；不使用来路不明的包。

## 6. 实现边界

**做**

- 启动/关闭生命周期、配置加载与校验、错误码表、日志初始化、静态页挂载、安全校验中间件、健康与系统信息两个接口、数据目录与日志目录创建。

**不做**

- 不建数据库、不写迁移、不写任何业务实体。
- 不接千问、不读 Keychain、不读字幕、不写词条。
- 不做前端路由与业务页面（占位页即可）。
- 不做备份、导出、自动更新、开机自启。

## 7. 自动化测试要求

必须覆盖（pytest，使用测试客户端，不启动真实外网）：

1. 健康检查返回 `200` 且字段/类型符合约定，响应中不含路径、配置、令牌。
2. `Host` 为公网域名或局域网 IP 时返回 `403`。
3. `POST` 带外站 `Origin` 时被拒绝；同源 `Origin` 通过。
4. 缺少令牌访问受保护接口返回 `401`；错误令牌返回 `401`；正确令牌返回 `200`。
5. 响应头包含 CSP、`nosniff`、`Referrer-Policy`。
6. 构造包含令牌与查询串的请求，断言日志文件中**不出现**令牌与原样查询串。
7. 配置非法（端口越界、数据目录不可写）时启动失败，错误信息可读，不伪造成功。
8. 数据目录创建后权限为 `0700`。

测试不得依赖真实时间、真实用户目录：使用临时目录与可注入配置。

## 8. 人工验收标准

1. 按报告中的命令启动，终端打印监听地址，无异常堆栈。
2. 浏览器打开首页，显示骨架页；页面不发任何外部请求（含字体、CDN）。
3. 终端 `curl http://127.0.0.1:<port>/api/v1/health` 返回 `200` 与预期字段。
4. 用同一局域网的另一台设备访问 `http://<本机局域网 IP>:<port>` **失败**（连接被拒绝）。
5. 浏览器开发者工具查看响应头，确认 CSP、`nosniff`、`Referrer-Policy` 存在。
6. 查看 `logs/` 当日日志：无令牌、无请求体、无个人路径以外的敏感内容。
7. 关闭应用后进程退出，端口释放；再次启动可正常服务。

## 9. 禁止事项

- 禁止监听 `0.0.0.0`、`::` 或任何对外地址；禁止“临时”关闭校验。
- 禁止 CORS `allow_origins=["*"]`。
- 禁止把令牌写入磁盘、日志、URL、前端源码明文以外的位置（页面注入属允许方式，但需不可被外部读取）。
- 禁止在本任务创建数据库表或写业务接口。
- 禁止引入 React/Vue/Node 工具链、CSS 框架或外部 CDN。
- 禁止修改 `docs/`、`CLAUDE.md`、`AGENTS.md`、`README.md`。
- 禁止以 `--reload` 作为默认运行方式交付。
- 禁止提交或推送，除非用户明确批准。
