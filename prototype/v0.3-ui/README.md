# SceneLingo V0.3 UI 原型

这是独立 HTML/CSS/JavaScript 演示原型，不连接正式应用、SQLite 或千问；页面不加载在线字体或其他在线资源，可离线打开。

学习首页会根据Mac本地时间展示时段问候，并按本地日历日期稳定选择每日鼓励语；同一天刷新不会变，跨日后自动更新。鼓励语当前完全来自本地内置列表。

## 打开

在 Finder 中双击本目录的 `index.html`，或将它拖入 Chrome。无需安装依赖或启动服务。建议 Chrome 窗口宽度至少 1280px，以同时显示工作台三栏。

## 可操作内容与演示范围

- 左侧导航可在学习首页、工作台、生词库和复习页间切换。
- 工作台资料卡可切换选中状态；字幕句子可切换当前语境，点击单词打开演示词卡，可查看本地写在原型内的演示 IPA/释义，并可触发浏览器语音朗读。
- 保存单词只改变当前页面的演示生词库；收藏和工作台布局保存在当前浏览器的 `localStorage`。点击资料栏标题旁的 ↔（无障碍名称“恢复默认布局”）可清除已保存的布局并恢复默认宽度。
- 三栏分隔线可拖动。字幕列表、词汇列表和聊天消息区域各自滚动。
- AI Tutor 的快捷提问、Enter 发送、新建/清空会话、历史入口均为本地模拟；不会发送任何内容到网络，也不会调用AI。
- 导入按钮只演示文件选择，不会读取或解析字幕；播放、复习结果、首页学习指标及词卡释义也是演示数据。此原型不能用于真实学习记录。

## 问候逻辑测试

在项目根目录执行：

```bash
node --test prototype/v0.3-ui/tests/daily-greeting.test.cjs
```

测试使用构造的本地 `Date` 输入，不修改Mac系统时间。浏览器内也可在控制台设置 `window.SceneLingoGreetingClock = () => new Date(2026, 10, 2, 5, 0)` 并运行 `SceneLingoDailyGreeting.refresh()` 模拟指定时间。

## 未来AI接入边界

`assets/daily-greeting.js` 中的 `aiGreetingProvider` 是禁用的占位适配器，始终返回 `null`，不会发起请求。正式应用接入位置是该适配器对应的服务层：由现有FastAPI复用千问网关与macOS Keychain处理凭据和请求。启用前必须在设置中单独说明联网及可能产生费用并取得授权；服务端需按本地日期缓存、保证每天至多请求一次，失败时回退本地文案，且不附带字幕或学习记录。本原型没有API设置，也不会产生模型调用或费用。
