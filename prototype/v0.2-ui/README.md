# SceneLingo V0.2 · 学习工作台原型

独立的桌面端交互原型，用来在改正式应用之前确认新版信息架构与学习体验。原型只包含静态 HTML / CSS / JavaScript，**不接入正式应用、数据库或千问 API**，所有内容均为原创模拟数据。

## 打开方式

直接用 Chrome 打开：

`prototype/v0.2-ui/index.html`

也可以在终端执行：

```bash
open -a "Google Chrome" prototype/v0.2-ui/index.html
```

无需安装依赖，无需启动服务器。页面通过 `file://` 运行，断网也可使用。

## 页面与操作

| 页面 | 路由 | 可体验的操作 |
| --- | --- | --- |
| 学习首页 | `#/home` | 继续学习、今日目标、每周学习时长、最近学习 |
| 学习工作台 | `#/workbench` | 切换剧集、点击字幕跳转、逐句播放、点击单词查词、和 AI Tutor 对话 |
| 单词详情卡 | 工作台内浮层 | 查看美式音标与中文释义、本地朗读、加入生词库、请 AI 讲解 |
| 生词库 | `#/vocabulary` | 按状态筛选、搜索、进入复习 |
| 复习 | 生词库内流程 | 先回忆再翻面，选择“忘记 / 模糊 / 记住”，完成后查看本轮结果 |
| 学习统计 | `#/stats` | 学习概览、每周趋势、掌握度、学习热力图、最近活动 |

主要交互：

- 左侧导航在四个页面间切换，当前页有明确高亮。
- 工作台三栏布局：剧集列表 / 字幕阅读区 / AI Tutor，可同时查看字幕和对话。
- 字幕区独立滚动，点击任意单词弹出详情卡；浮层不会遮住 AI Tutor。
- “加入生词库”会即时更新导航计数，并在当前原型会话内保留。
- 点击“问 AI”会把单词带到右侧 Tutor，回复由本地规则生成，不发送网络请求。
- 单词朗读调用浏览器本地 `speechSynthesis`（`en-US`），不调用云端 TTS。
- 逐句播放会按模拟时间轴推进字幕，播放到末尾自动停止。

## 验证

在项目目录执行：

```bash
cd prototype/v0.2-ui
node check-ui.mjs
```

脚本会调用系统 Chrome（`/Applications/Google Chrome.app`）以无头模式检查 1440×900、1280×800、1024×640（近似 125% 缩放）三种宽度，覆盖导航、三栏布局、字幕独立滚动、查词浮层、加入生词库、本地朗读、AI 对话、筛选搜索、复习和统计，并把截图写入 `reports/`。

最新一次检查结果：`ok: true`，控制台异常 0，页面异常 0，外部网络请求 0。

## 文件说明

```
index.html          应用外壳、侧边导航、浮层与 toast
assets/data.js      原创剧集字幕、词典、生词与统计模拟数据
assets/styles.css   设计令牌与全部布局/组件样式
assets/app.js       路由、渲染与交互逻辑
check-ui.mjs        无依赖 Chrome DevTools 自动化检查
reports/            检查过程中生成的临时界面截图（不纳入 Git）
```

## 已知限制

- 这是界面原型，刷新页面后状态会重置，不会写入真实学习记录。
- 125% 浏览器缩放使用 1024×640 CSS 视口近似验证，未在真实浏览器缩放菜单下逐项核对。
- 无头 Chrome 只能验证朗读按钮与 `speechSynthesis` 调用路径、提示文案，无法验证实际音频是否可听；请在本地 Chrome 中亲自试听。
- 原型不修改 `app/`、`tests/`、数据库或现有 API，也不代表 V0.2 功能已经接入正式后端。
